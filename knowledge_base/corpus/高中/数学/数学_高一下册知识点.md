# 高一下册数学核心知识点

## 第一章 三角函数

### 1.1 任意角与弧度制
- **任意角**：正角（逆时针）、负角（顺时针）、零角
- **象限角**：终边落在第几象限，该角就是第几象限角
- **弧度制**：1弧度 = 180°/π ≈ 57.3°
- **弧长公式**：l = |α|r（α为弧度）
- **扇形面积**：S = (1/2)lr = (1/2)α r²

### 1.2 三角函数定义
设角α终边上任意一点P(x, y)，r = √(x² + y²)，则：
- sin α = y/r
- cos α = x/r
- tan α = y/x (x ≠ 0)

**单位圆定义**：在单位圆中，sin α = y坐标，cos α = x坐标

### 1.3 同角三角函数关系
- **平方关系**：sin²α + cos²α = 1
- **商数关系**：tan α = sin α / cos α
- **倒数关系**：tan α · cot α = 1

### 1.4 诱导公式
**口诀**：奇变偶不变，符号看象限

- sin(π/2 ± α) = cos α
- cos(π/2 ± α) = ∓sin α
- sin(π ± α) = ∓sin α
- cos(π ± α) = -cos α
- sin(-α) = -sin α（奇函数）
- cos(-α) = cos α（偶函数）

### 1.5 三角函数图像与性质

**正弦函数 y = sin x**：
- 定义域：R，值域：[-1, 1]
- 周期：T = 2π
- 奇偶性：奇函数
- 单调性：[2kπ - π/2, 2kπ + π/2]递增
- 对称轴：x = kπ + π/2，对称中心：(kπ, 0)

**余弦函数 y = cos x**：
- 定义域：R，值域：[-1, 1]
- 周期：T = 2π
- 奇偶性：偶函数
- 单调性：[2kπ, 2kπ + π]递减
- 对称轴：x = kπ，对称中心：(kπ + π/2, 0)

**正切函数 y = tan x**：
- 定义域：x ≠ kπ + π/2，值域：R
- 周期：T = π
- 奇偶性：奇函数
- 单调性：(kπ - π/2, kπ + π/2)递增
- 对称中心：(kπ/2, 0)

### 1.6 函数 y = A sin(ωx + φ) 的图像
- **振幅**：A（|A|为最大值）
- **周期**：T = 2π/|ω|
- **频率**：f = 1/T = |ω|/(2π)
- **初相**：φ
- **相位**：ωx + φ

**图像变换顺序**：
1. 左右平移：y = sin(x + φ)
2. 伸缩变换：y = sin(ωx + φ)
3. 纵向伸缩：y = A sin(ωx + φ)

### 1.7 三角恒等变换

**两角和差公式**：
- sin(α ± β) = sin α cos β ± cos α sin β
- cos(α ± β) = cos α cos β ∓ sin α sin β
- tan(α ± β) = (tan α ± tan β) / (1 ∓ tan α tan β)

**二倍角公式**：
- sin 2α = 2sin α cos α
- cos 2α = cos²α - sin²α = 2cos²α - 1 = 1 - 2sin²α
- tan 2α = 2tan α / (1 - tan²α)

**辅助角公式**：
a sin x + b cos x = √(a² + b²) sin(x + φ)
其中 tan φ = b/a

## 第二章 平面向量

### 2.1 向量基本概念
- **向量**：既有大小又有方向的量
- **模**：向量的长度，记作|a⃗|
- **零向量**：模为0的向量，记作0⃗
- **单位向量**：模为1的向量
- **相等向量**：大小相等、方向相同
- **平行向量（共线向量）**：方向相同或相反

### 2.2 向量的线性运算

**加法**：
- 三角形法则：首尾相接
- 平行四边形法则：共起点

**减法**：
a⃗ - b⃗ = a⃗ + (-b⃗)（指向被减向量）

**数乘**：
- |λa⃗| = |λ| · |a⃗|
- λ > 0时，λa⃗与a⃗同向
- λ < 0时，λa⃗与a⃗反向

**共线定理**：
a⃗ ∥ b⃗ ⟺ a⃗ = λb⃗（b⃗ ≠ 0⃗）

### 2.3 平面向量基本定理
若e₁⃗、e₂⃗不共线，则平面内任一向量a⃗可唯一表示为：
a⃗ = λ₁e₁⃗ + λ₂e₂⃗

### 2.4 向量的坐标表示
设a⃗ = (x₁, y₁)，b⃗ = (x₂, y₂)，则：
- a⃗ + b⃗ = (x₁ + x₂, y₁ + y₂)
- a⃗ - b⃗ = (x₁ - x₂, y₁ - y₂)
- λa⃗ = (λx₁, λy₁)
- |a⃗| = √(x₁² + y₁²)
- a⃗ ∥ b⃗ ⟺ x₁y₂ - x₂y₁ = 0

### 2.5 平面向量数量积

**定义**：
a⃗ · b⃗ = |a⃗| |b⃗| cos θ

**几何意义**：
a⃗在b⃗方向上的投影 × |b⃗|

**坐标运算**：
a⃗ · b⃗ = x₁x₂ + y₁y₂

**性质**：
- a⃗ ⊥ b⃗ ⟺ a⃗ · b⃗ = 0 ⟺ x₁x₂ + y₁y₂ = 0
- cos θ = (a⃗ · b⃗) / (|a⃗| |b⃗|)
- |a⃗|² = a⃗ · a⃗ = x₁² + y₁²

**运算律**：
- 交换律：a⃗ · b⃗ = b⃗ · a⃗
- 分配律：(a⃗ + b⃗) · c⃗ = a⃗ · c⃗ + b⃗ · c⃗
- 数乘结合律：(λa⃗) · b⃗ = λ(a⃗ · b⃗)

### 2.6 向量的应用

**平面几何中的应用**：
- 证明平行：向量共线
- 证明垂直：数量积为0
- 求距离：向量的模
- 求角度：数量积公式

**物理中的应用**：
- 力的合成与分解
- 速度的合成与分解
- 位移计算

## 第三章 解三角形

### 3.1 正弦定理
a/sin A = b/sin B = c/sin C = 2R（R为外接圆半径）

**变形**：
- a = 2R sin A，b = 2R sin B，c = 2R sin C
- sin A/a = sin B/b = sin C/c
- a:b:c = sin A:sin B:sin C

### 3.2 余弦定理
- a² = b² + c² - 2bc cos A
- b² = a² + c² - 2ac cos B
- c² = a² + b² - 2ab cos C

**变形**：
cos A = (b² + c² - a²) / (2bc)

### 3.3 三角形面积公式
- S = (1/2)ab sin C = (1/2)bc sin A = (1/2)ac sin B
- S = (1/2) × 底 × 高
- 海伦公式：S = √[p(p-a)(p-b)(p-c)]，其中p = (a+b+c)/2

### 3.4 解三角形的应用
- **测量距离**：利用正弦定理、余弦定理
- **测量高度**：仰角、俯角问题
- **航海问题**：方位角、航向角

## 易错提醒

1. **弧度制与角度制混用**：计算时注意单位统一
2. **诱导公式符号判断**：先判断象限，再确定符号
3. **向量平行与垂直**：平行用坐标叉乘，垂直用数量积
4. **三角函数周期**：tan x周期为π，sin x和cos x周期为2π
5. **解三角形**：注意判断解的个数（一解、两解、无解）
6. **数量积不满足消去律**：a⃗ · b⃗ = a⃗ · c⃗不能推出b⃗ = c⃗
