# 高一上册数学核心知识点

## 第一章 集合与常用逻辑用语

### 1.1 集合的概念与表示
- **集合定义**：具有某种特定性质的对象的总体
- **表示方法**：
  - 列举法：{1, 2, 3, 4, 5}
  - 描述法：{x | x > 0}
- **常用数集**：N（自然数）、Z（整数）、Q（有理数）、R（实数）
- **集合关系**：∈（属于）、⊆（包含）、⊂（真包含）

### 1.2 集合的基本运算
- **交集**：A ∩ B = {x | x ∈ A 且 x ∈ B}
- **并集**：A ∪ B = {x | x ∈ A 或 x ∈ B}
- **补集**：∁ᵤA = {x | x ∈ U 且 x ∉ A}
- **性质**：A ∩ A = A，A ∪ ∅ = A，∁ᵤ(∁ᵤA) = A

### 1.3 充分条件与必要条件
- p ⇒ q：p是q的充分条件，q是p的必要条件
- p ⇔ q：p是q的充要条件
- 判断方法：集合法、定义法、逆否命题法

## 第二章 一元二次函数、方程和不等式

### 2.1 等式性质与不等式性质
- **基本性质**：
  - a > b ⇒ a + c > b + c
  - a > b, c > 0 ⇒ ac > bc
  - a > b > 0 ⇒ a² > b²
- **均值不等式**：a + b ≥ 2√(ab)（a, b > 0，当且仅当a = b时取等号）

### 2.2 基本不等式的应用
- **最值问题**：已知xy = S（定值），求x + y的最小值
- **配凑技巧**：凑系数、凑项、分离常数
- **注意条件**：一正、二定、三相等

### 2.3 二次函数与一元二次方程
- **标准形式**：y = ax² + bx + c（a ≠ 0）
- **顶点式**：y = a(x - h)² + k，顶点(h, k)
- **判别式**：Δ = b² - 4ac
  - Δ > 0：两个不等实根
  - Δ = 0：两个相等实根
  - Δ < 0：无实根
- **韦达定理**：x₁ + x₂ = -b/a，x₁x₂ = c/a

## 第三章 函数的概念与性质

### 3.1 函数的概念
- **定义**：设A、B是非空数集，若按某种对应关系f，使A中任意元素x，在B中有唯一确定的y与之对应，则f: A → B为函数
- **三要素**：定义域、值域、对应关系
- **表示方法**：解析法、图像法、列表法

### 3.2 函数的基本性质
- **单调性**：
  - 增函数：x₁ < x₂ ⇒ f(x₁) < f(x₂)
  - 减函数：x₁ < x₂ ⇒ f(x₁) > f(x₂)
  - 判断方法：定义法、导数法、图像法

- **奇偶性**：
  - 奇函数：f(-x) = -f(x)，图像关于原点对称
  - 偶函数：f(-x) = f(x)，图像关于y轴对称
  - 前提：定义域关于原点对称

### 3.3 幂函数
- **定义**：y = xᵅ（α为常数）
- **常见幂函数**：y = x, y = x², y = x³, y = √x, y = 1/x
- **性质**：过点(1, 1)，在第一象限单调性由α决定

## 第四章 指数函数与对数函数

### 4.1 指数与指数幂的运算
- **整数指数幂**：aⁿ = a × a × ... × a（n个a相乘）
- **分数指数幂**：a^(m/n) = ⁿ√(aᵐ)（a > 0，m、n ∈ N*，n > 1）
- **运算法则**：
  - aᵐ · aⁿ = a^(m+n)
  - (aᵐ)ⁿ = a^(mn)
  - (ab)ⁿ = aⁿbⁿ

### 4.2 指数函数
- **定义**：y = aˣ（a > 0且a ≠ 1）
- **性质**：
  - 定义域R，值域(0, +∞)
  - 过点(0, 1)
  - a > 1时单调递增，0 < a < 1时单调递减
  - 图像在x轴上方

### 4.3 对数与对数运算
- **定义**：aˣ = N ⇔ x = logₐN（a > 0，a ≠ 1，N > 0）
- **运算法则**：
  - logₐ(MN) = logₐM + logₐN
  - logₐ(M/N) = logₐM - logₐN
  - logₐMⁿ = n·logₐM
- **换底公式**：logₐb = (logᴄb)/(logᴄa)
- **特殊值**：logₐ1 = 0，logₐa = 1

### 4.4 对数函数
- **定义**：y = logₐx（a > 0且a ≠ 1）
- **性质**：
  - 定义域(0, +∞)，值域R
  - 过点(1, 0)
  - a > 1时单调递增，0 < a < 1时单调递减
  - 与指数函数y = aˣ互为反函数

## 第五章 三角函数

### 5.1 任意角和弧度制
- **角度制与弧度制**：180° = π rad
- **弧长公式**：l = |α|r（α为弧度）
- **扇形面积**：S = (1/2)lr = (1/2)r²|α|

### 5.2 三角函数定义
- **单位圆定义**：
  - sin α = y/r
  - cos α = x/r
  - tan α = y/x（x ≠ 0）
- **特殊角三角函数值**：记住0°、30°、45°、60°、90°

### 5.3 同角三角函数关系
- **平方关系**：sin²α + cos²α = 1
- **商数关系**：tan α = sin α / cos α
- **倒数关系**：tan α · cot α = 1

### 5.4 诱导公式
- **口诀**：奇变偶不变，符号看象限
- **常用公式**：
  - sin(π - α) = sin α
  - cos(π - α) = -cos α
  - sin(π + α) = -sin α
  - cos(π + α) = -cos α

## 易错点提醒

1. **集合运算**：注意空集∅的特殊性，∅是任何集合的子集
2. **函数定义域**：分式分母不为0，偶次根式被开方数≥0，对数真数>0
3. **指数对数互化**：注意底数和真数的取值范围
4. **三角函数符号**：根据角所在象限判断正负
5. **均值不等式**：使用条件"一正二定三相等"缺一不可
