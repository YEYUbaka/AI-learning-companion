# 高二上册数学核心知识点

## 第一章 空间向量与立体几何

### 1.1 空间向量基本概念
- **空间向量**：具有大小和方向的量
- **共线向量**：方向相同或相反
- **共面向量**：平行于同一平面的向量
- **空间向量基本定理**：若a⃗、b⃗、c⃗不共面，则空间任一向量p⃗可唯一表示为 p⃗ = xa⃗ + yb⃗ + zc⃗

### 1.2 空间向量的坐标运算
设a⃗ = (x₁, y₁, z₁)，b⃗ = (x₂, y₂, z₂)
- **加减法**：a⃗ ± b⃗ = (x₁ ± x₂, y₁ ± y₂, z₁ ± z₂)
- **数乘**：λa⃗ = (λx₁, λy₁, λz₁)
- **模长**：|a⃗| = √(x₁² + y₁² + z₁²)
- **数量积**：a⃗ · b⃗ = x₁x₂ + y₁y₂ + z₁z₂

### 1.3 空间位置关系的向量表示
- **平行**：a⃗ ∥ b⃗ ⟺ a⃗ = λb⃗ ⟺ x₁/x₂ = y₁/y₂ = z₁/z₂
- **垂直**：a⃗ ⊥ b⃗ ⟺ a⃗ · b⃗ = 0 ⟺ x₁x₂ + y₁y₂ + z₁z₂ = 0
- **夹角**：cos θ = (a⃗ · b⃗) / (|a⃗| |b⃗|)

### 1.4 平面的法向量
若n⃗ ⊥ 平面α内所有向量，则n⃗为平面α的法向量

**求法向量步骤**：
1. 设n⃗ = (x, y, z)
2. 找平面内两个不共线向量a⃗、b⃗
3. 列方程组：n⃗ · a⃗ = 0，n⃗ · b⃗ = 0
4. 解方程组（通常令z=1或x=1）

### 1.5 空间角的计算

**异面直线所成角**：
cos θ = |a⃗ · b⃗| / (|a⃗| |b⃗|)（取锐角或直角）

**直线与平面所成角**：
sin θ = |cos⟨a⃗, n⃗⟩| = |a⃗ · n⃗| / (|a⃗| |n⃗|)

**二面角**：
cos θ = |n₁⃗ · n₂⃗| / (|n₁⃗| |n₂⃗|)（注意正负）

### 1.6 空间距离的计算
**点到平面距离**：
d = |AP⃗ · n⃗| / |n⃗|（P为平面内任一点，A为平面外的点）

## 第二章 直线和圆的方程

### 2.1 直线的倾斜角与斜率
- **倾斜角**：α ∈ [0°, 180°)
- **斜率**：k = tan α（α ≠ 90°）
- **两点斜率**：k = (y₂ - y₁) / (x₂ - x₁)

### 2.2 直线方程的五种形式
1. **点斜式**：y - y₀ = k(x - x₀)
2. **斜截式**：y = kx + b
3. **两点式**：(y - y₁)/(y₂ - y₁) = (x - x₁)/(x₂ - x₁)
4. **截距式**：x/a + y/b = 1
5. **一般式**：Ax + By + C = 0

### 2.3 两直线位置关系
设l₁: A₁x + B₁y + C₁ = 0，l₂: A₂x + B₂y + C₂ = 0
- **平行**：A₁/A₂ = B₁/B₂ ≠ C₁/C₂
- **重合**：A₁/A₂ = B₁/B₂ = C₁/C₂
- **相交**：A₁/A₂ ≠ B₁/B₂
- **垂直**：A₁A₂ + B₁B₂ = 0

### 2.4 距离公式
- **两点距离**：d = √[(x₂-x₁)² + (y₂-y₁)²]
- **点到直线距离**：d = |Ax₀ + By₀ + C| / √(A² + B²)
- **平行线距离**：d = |C₁ - C₂| / √(A² + B²)

### 2.5 圆的方程
- **标准方程**：(x - a)² + (y - b)² = r²
- **一般方程**：x² + y² + Dx + Ey + F = 0（D² + E² - 4F > 0）
- **圆心**：(-D/2, -E/2)，半径：r = √(D² + E² - 4F) / 2

### 2.6 直线与圆的位置关系
设圆心到直线距离为d，半径为r
- **相离**：d > r（Δ < 0）
- **相切**：d = r（Δ = 0）
- **相交**：d < r（Δ > 0）

## 第三章 圆锥曲线

### 3.1 椭圆

**定义**：|PF₁| + |PF₂| = 2a（2a > |F₁F₂|）

**标准方程**：
- 焦点在x轴：x²/a² + y²/b² = 1（a > b > 0）
- 焦点在y轴：y²/a² + x²/b² = 1（a > b > 0）

**几何性质**：
- 关系式：a² = b² + c²
- 离心率：e = c/a ∈ (0, 1)
- 焦点：(±c, 0)或(0, ±c)
- 顶点：(±a, 0)、(0, ±b)
- 长轴长：2a，短轴长：2b
- 焦距：2c

**焦点三角形**：
S△F₁PF₂ = b² tan(θ/2)（θ为∠F₁PF₂）

### 3.2 双曲线

**定义**：||PF₁| - |PF₂|| = 2a（2a < |F₁F₂|）

**标准方程**：
- 焦点在x轴：x²/a² - y²/b² = 1
- 焦点在y轴：y²/a² - x²/b² = 1

**几何性质**：
- 关系式：c² = a² + b²
- 离心率：e = c/a > 1
- 焦点：(±c, 0)或(0, ±c)
- 顶点：(±a, 0)或(0, ±a)
- 渐近线：y = ±(b/a)x（焦点在x轴）

**共渐近线双曲线系**：
x²/a² - y²/b² = λ（λ ≠ 0）

### 3.3 抛物线

**定义**：|PF| = d（点到焦点距离等于到准线距离）

**标准方程**（p > 0）：
- y² = 2px（开口向右）
- y² = -2px（开口向左）
- x² = 2py（开口向上）
- x² = -2py（开口向下）

**几何性质**（以y² = 2px为例）：
- 焦点：F(p/2, 0)
- 准线：x = -p/2
- 离心率：e = 1
- 焦半径：|PF| = x₀ + p/2

**焦点弦性质**：
若AB过焦点，则1/|AF| + 1/|BF| = 2/p

### 3.4 圆锥曲线的统一定义
|PF| / d = e（e为离心率，d为点到准线距离）
- e < 1：椭圆
- e = 1：抛物线
- e > 1：双曲线

### 3.5 直线与圆锥曲线
**联立方程法**：
1. 联立直线与曲线方程
2. 消元得一元二次方程
3. 利用韦达定理：x₁ + x₂ = -b/a，x₁x₂ = c/a
4. 弦长公式：|AB| = √(1 + k²) |x₁ - x₂|

**点差法**（中点弦问题）：
设A(x₁, y₁)、B(x₂, y₂)，代入曲线方程后作差

## 易错提醒

1. **空间向量建系**：选择合适的坐标系，通常以长方体或正方体为基础
2. **法向量求解**：方程组有无穷多解，通常令某个坐标为1
3. **二面角正负**：根据图形判断锐角还是钝角
4. **椭圆与双曲线**：注意a、b、c的关系式不同
5. **离心率范围**：椭圆(0,1)，双曲线(1,+∞)，抛物线=1
6. **焦点位置**：看分母大小（椭圆）或正负号（双曲线）
7. **韦达定理应用**：先判断Δ > 0保证相交

## 重点题型

1. 用空间向量证明平行、垂直关系
2. 求空间角（异面直线角、线面角、二面角）
3. 求点到平面距离
4. 求圆锥曲线的标准方程
5. 直线与圆锥曲线的位置关系
6. 弦长、中点弦、焦点弦问题
7. 离心率的取值范围
