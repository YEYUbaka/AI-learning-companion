# 高二下册数学核心知识点

## 第一章 数列

### 1.1 数列的概念
- **数列**：按一定顺序排列的一列数
- **通项公式**：an = f(n)
- **递推公式**：an+1 = f(an)
- **前n项和**：Sn = a1 + a2 + ... + an

### 1.2 等差数列

**定义**：an+1 - an = d（公差）

**通项公式**：
- an = a1 + (n-1)d
- an = am + (n-m)d

**前n项和**：
- Sn = n(a1 + an)/2
- Sn = na1 + n(n-1)d/2

**性质**：
- 若m + n = p + q，则am + an = ap + aq
- 等差中项：2an = an-1 + an+1
- Sn、S2n - Sn、S3n - S2n成等差数列

### 1.3 等比数列

**定义**：an+1/an = q（公比，q ≠ 0）

**通项公式**：
- an = a1 · q^(n-1)
- an = am · q^(n-m)

**前n项和**：
- q = 1时：Sn = na1
- q ≠ 1时：Sn = a1(1 - q^n)/(1 - q) = (a1 - an·q)/(1 - q)

**性质**：
- 若m + n = p + q，则am · an = ap · aq
- 等比中项：an² = an-1 · an+1
- Sn、S2n - Sn、S3n - S2n成等比数列（q ≠ -1）

### 1.4 数列求和方法

**公式法**：
- 等差、等比数列直接套用公式

**分组求和法**：
- 将数列分成几个等差或等比数列

**裂项相消法**：
- 1/(n(n+1)) = 1/n - 1/(n+1)
- 1/(2n-1)(2n+1) = 1/2[1/(2n-1) - 1/(2n+1)]

**错位相减法**：
- 适用于{an·bn}型，其中{an}为等差，{bn}为等比

**倒序相加法**：
- Sn = a1 + a2 + ... + an
- Sn = an + an-1 + ... + a1

### 1.5 数学归纳法

**步骤**：
1. 验证n = n0时命题成立（奠基）
2. 假设n = k时命题成立
3. 证明n = k+1时命题也成立（归纳）
4. 结论：命题对所有n ≥ n0成立

## 第二章 导数及其应用

### 2.1 导数的概念

**平均变化率**：
Δy/Δx = [f(x0 + Δx) - f(x0)]/Δx

**导数定义**：
f'(x0) = lim(Δx→0) [f(x0 + Δx) - f(x0)]/Δx

**几何意义**：
切线斜率 k = f'(x0)

**物理意义**：
瞬时速度、瞬时变化率

### 2.2 基本初等函数的导数

- (C)' = 0
- (x^n)' = nx^(n-1)
- (sin x)' = cos x
- (cos x)' = -sin x
- (e^x)' = e^x
- (a^x)' = a^x ln a
- (ln x)' = 1/x
- (log_a x)' = 1/(x ln a)

### 2.3 导数运算法则

**四则运算**：
- [u(x) ± v(x)]' = u'(x) ± v'(x)
- [u(x)v(x)]' = u'(x)v(x) + u(x)v'(x)
- [u(x)/v(x)]' = [u'(x)v(x) - u(x)v'(x)]/v²(x)

**复合函数求导（链式法则）**：
[f(g(x))]' = f'(g(x)) · g'(x)

### 2.4 导数的应用

**单调性**：
- f'(x) > 0 ⟹ f(x)在该区间递增
- f'(x) < 0 ⟹ f(x)在该区间递减
- f'(x) = 0的点可能是极值点

**极值**：
1. 求f'(x) = 0的根（驻点）
2. 判断驻点左右导数符号
3. 左正右负为极大值，左负右正为极小值

**最值**：
1. 求区间内所有极值点
2. 计算极值和端点值
3. 比较得出最大值和最小值

**切线方程**：
过点(x0, y0)的切线：y - y0 = f'(x0)(x - x0)

### 2.5 导数的综合应用

**函数图像**：
- 利用导数判断单调性、极值点
- 描绘函数大致图像

**不等式证明**：
- 构造函数f(x) = g(x) - h(x)
- 利用导数判断f(x)的符号

**恒成立问题**：
- f(x) ≥ 0恒成立 ⟺ f(x)min ≥ 0
- f(x) ≤ 0恒成立 ⟺ f(x)max ≤ 0

**零点问题**：
- 利用导数判断函数单调性
- 结合零点存在定理

**参数范围**：
- 分离参数法
- 数形结合法
- 分类讨论法

## 易错提醒

1. **数列求和**：等比数列q=1时单独讨论
2. **裂项相消**：注意首尾项，中间项相消
3. **错位相减**：两式相减时对齐项
4. **导数定义**：Δx→0，不是Δx=0
5. **极值点**：f'(x0)=0不一定是极值点，需判断左右符号
6. **最值**：别忘记比较端点值
7. **复合函数求导**：别忘记乘内层导数
8. **切线与法线**：切线斜率k，法线斜率-1/k
