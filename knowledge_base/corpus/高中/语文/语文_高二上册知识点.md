# 高二上册语文核心知识点

## 第一部分 现代文阅读

### 1.1 论述类文本阅读
**文体特征**：以议论为主，阐述观点、分析问题

**阅读技巧**：
- 筛选整合信息：找准关键词句
- 分析论证结构：总分总、并列、递进
- 理解核心观点：找中心论点和分论点
- 辨析概念内涵：准确理解专业术语

**常见题型**：
- 信息筛选题：原文有无、是否正确
- 推断题：合理推断、过度推断
- 概括题：概括论点、论据、论证方法

### 1.2 文学类文本阅读
**小说阅读**：
- 情节：开端、发展、高潮、结局
- 人物：外貌、语言、动作、心理、细节描写
- 环境：自然环境、社会环境
- 主题：通过情节、人物、环境揭示

**散文阅读**：
- 线索：时间、空间、情感、事物
- 手法：借景抒情、托物言志、象征
- 语言：品味关键词句的表达效果
- 情感：把握作者情感变化

**阅读方法**：
- 整体感知：理清思路、把握主旨
- 局部品析：赏析语言、分析手法
- 联系拓展：联系背景、作者经历

### 1.3 实用类文本阅读
**新闻类**：
- 结构：标题、导语、主体、背景、结语
- 特点：真实性、时效性、准确性
- 分析：新闻价值、报道角度、语言特色

**传记类**：
- 真实性与文学性结合
- 把握传主形象和精神品质
- 分析选材组材特点

**科普类**：
- 说明对象及特征
- 说明方法及作用
- 说明顺序和语言准确性

## 第二部分 古代诗文阅读

### 2.1 文言文阅读

**实词积累**：
- 一词多义：根据语境判断
- 古今异义：注意词义变化
- 词类活用：名动、形动、使动、意动
- 通假字：音同或音近的字互相替代

**虚词用法**：
- 而、以、于、之、其、者、乃、则、焉、也

**句式特点**：
- 判断句：...者...也
- 被动句：为...所、见...于
- 倒装句：宾语前置、定语后置、状语后置
- 省略句：主语、宾语、介词省略

**翻译技巧**：
- 直译为主，意译为辅
- 留（专有名词）、删（虚词）、补（省略）、换（古今异义）、调（倒装）

### 2.2 古代诗歌鉴赏

**诗歌分类**：
- 按内容：山水田园、边塞战争、咏史怀古、送别思乡、咏物言志
- 按体裁：古体诗、近体诗（律诗、绝句）、词、曲

**表达技巧**：
- 修辞手法：比喻、拟人、夸张、对偶、排比、反问
- 表现手法：借景抒情、托物言志、虚实结合、动静结合、对比衬托
- 描写手法：正面描写、侧面描写、细节描写、白描

**意象意境**：
- 常见意象：月（思乡）、柳（离别）、梅（高洁）、菊（隐逸）
- 意境特点：雄浑壮阔、清新明丽、沉郁悲凉、恬淡闲适

**情感主题**：
- 思乡怀人、羁旅愁思
- 建功立业、报国无门
- 山水田园、隐逸情怀
- 离愁别绪、相思之情

### 2.3 名篇名句默写
**方法**：
- 理解记忆：理解诗句含义
- 联想记忆：前后句联系
- 注意易错字：通假字、生僻字

## 第三部分 语言文字运用

### 3.1 词语运用
- 近义词辨析：感情色彩、语义轻重、搭配对象
- 成语运用：望文生义、张冠李戴、褒贬误用
- 熟语俗语：理解含义、把握语境

### 3.2 病句辨析
**六大类型**：
- 语序不当
- 搭配不当
- 成分残缺或赘余
- 结构混乱
- 表意不明
- 不合逻辑

### 3.3 语言表达
- 连贯：话题统一、句序合理、衔接自然
- 得体：场合、对象、目的、语体
- 简明：去除冗余、避免重复
- 生动：修辞手法、形象描写

### 3.4 修辞手法
- 比喻、拟人、夸张、排比、对偶、反复、设问、反问

## 第四部分 写作

### 4.1 议论文写作
**结构**：
- 引论：提出问题（是什么）
- 本论：分析问题（为什么）
- 结论：解决问题（怎么办）

**论证方法**：
- 举例论证：事实胜于雄辩
- 道理论证：引用名言警句
- 对比论证：正反对比
- 比喻论证：化抽象为具体

**写作技巧**：
- 标题：简洁明了、点明中心
- 开头：开门见山、引用名言、设置悬念
- 主体：分论点清晰、论据充分
- 结尾：总结全文、升华主题、发出号召

### 4.2 记叙文写作
**六要素**：时间、地点、人物、起因、经过、结果

**表达方式**：
- 记叙：顺叙、倒叙、插叙
- 描写：人物描写、环境描写
- 抒情：直接抒情、间接抒情

**写作要点**：
- 选材：真实、典型、新颖
- 立意：积极向上、深刻独特
- 细节：生动具体、感人至深

## 易错提醒

1. 文言实词翻译要结合语境
2. 诗歌鉴赏不能脱离文本
3. 病句辨析注意语法和逻辑
4. 作文审题要准确把握题意
5. 默写注意同音字、形近字

## 重点题型

1. 论述类文本信息筛选
2. 文学类文本人物形象分析
3. 文言文翻译
4. 古诗词意象意境分析
5. 语言运用综合题
6. 作文审题立意
