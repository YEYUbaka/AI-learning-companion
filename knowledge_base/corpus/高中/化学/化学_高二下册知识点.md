# 高二下册化学核心知识点

## 第一章 有机化合物的结构与性质

### 1.1 有机物的特点
- 多数含C、H、O、N等元素
- 多数难溶于水，易溶于有机溶剂
- 多数熔沸点较低
- 多数易燃烧
- 反应速率慢，常有副反应

### 1.2 有机物的分类
**按碳骨架**：链状、环状
**按官能团**：烃、烃的衍生物

### 1.3 同分异构体
**类型**：
- 碳链异构
- 位置异构
- 官能团异构

## 第二章 烃

### 2.1 烷烃
**通式**：CnH2n+2

**性质**：
- 取代反应：CH₄ + Cl₂ → CH₃Cl + HCl（光照）
- 氧化反应：燃烧

### 2.2 烯烃
**通式**：CnH2n

**性质**：
- 加成反应：CH₂=CH₂ + Br₂ → CH₂Br-CH₂Br
- 加聚反应：nCH₂=CH₂ → [-CH₂-CH₂-]n
- 氧化反应：燃烧、被KMnO₄氧化

### 2.3 炔烃
**通式**：CnH2n-2

**性质**：
- 加成反应
- 加聚反应

### 2.4 苯及其同系物
**结构**：平面正六边形，C-C键完全相同

**性质**：
- 取代反应：C₆H₆ + Br₂ → C₆H₅Br + HBr（Fe催化）
- 加成反应：C₆H₆ + 3H₂ → C₆H₁₂（Ni催化）
- 氧化反应：燃烧

## 第三章 烃的衍生物

### 3.1 卤代烃
**性质**：
- 水解反应：CH₃CH₂Br + NaOH → CH₃CH₂OH + NaBr
- 消去反应：CH₃CH₂Br + NaOH → CH₂=CH₂ + NaBr + H₂O

### 3.2 醇
**官能团**：-OH

**性质**：
- 氧化反应：2CH₃CH₂OH + O₂ → 2CH₃CHO + 2H₂O（Cu催化）
- 消去反应：CH₃CH₂OH → CH₂=CH₂ + H₂O（浓H₂SO₄，170℃）
- 取代反应：2CH₃CH₂OH + 2Na → 2CH₃CH₂ONa + H₂↑

### 3.3 酚
**代表物**：苯酚C₆H₅OH

**性质**：
- 弱酸性：C₆H₅OH + NaOH → C₆H₅ONa + H₂O
- 显色反应：遇FeCl₃溶液显紫色
- 取代反应：与Br₂反应生成白色沉淀

### 3.4 醛
**官能团**：-CHO

**性质**：
- 氧化反应：银镜反应、与新制Cu(OH)₂反应
- 加成反应：CH₃CHO + H₂ → CH₃CH₂OH

### 3.5 羧酸
**官能团**：-COOH

**性质**：
- 酸性：CH₃COOH + NaOH → CH₃COONa + H₂O
- 酯化反应：CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O

### 3.6 酯
**官能团**：-COO-

**性质**：
- 水解反应：CH₃COOCH₂CH₃ + NaOH → CH₃COONa + CH₃CH₂OH

## 第四章 糖类、油脂、蛋白质

### 4.1 糖类
**单糖**：葡萄糖、果糖
**二糖**：蔗糖、麦芽糖
**多糖**：淀粉、纤维素

**葡萄糖性质**：
- 氧化反应：银镜反应
- 还原反应：与新制Cu(OH)₂反应

### 4.2 油脂
**组成**：高级脂肪酸与甘油形成的酯

**性质**：
- 水解反应：油脂 + NaOH → 甘油 + 高级脂肪酸钠（肥皂）
- 加成反应：不饱和油脂 + H₂ → 饱和油脂

### 4.3 蛋白质
**组成**：氨基酸

**性质**：
- 水解反应：蛋白质 → 氨基酸
- 变性：加热、加酸碱、重金属盐
- 颜色反应：遇浓HNO₃变黄

## 易错提醒

1. 烷烃取代需要光照
2. 苯的取代需要催化剂
3. 醇的消去需要浓硫酸和加热
4. 酯化反应是可逆反应
5. 银镜反应需要水浴加热
