# 高一化学核心知识点

## 第一章 物质及其变化

### 1.1 物质的分类
- **单质与化合物**：
  - 单质：由同种元素组成（O₂、Fe、S）
  - 化合物：由不同元素组成（H₂O、NaCl）

- **酸碱盐氧化物**：
  - 酸：电离出H⁺（HCl、H₂SO₄、HNO₃）
  - 碱：电离出OH⁻（NaOH、Ca(OH)₂）
  - 盐：金属离子+酸根离子（NaCl、CuSO₄）
  - 氧化物：两种元素，一种是氧（CO₂、Fe₂O₃）

### 1.2 分散系
- **溶液**：分散质粒子直径 < 1 nm
- **胶体**：1 nm ~ 100 nm（丁达尔效应）
- **浊液**：> 100 nm

### 1.3 电解质
- **电解质**：水溶液或熔融状态能导电的化合物
- **强电解质**：完全电离（强酸、强碱、大多数盐）
- **弱电解质**：部分电离（弱酸、弱酸、水）
- **非电解质**：不导电的化合物（蔗糖、酒精）

## 第二章 离子反应

### 2.1 离子方程式
- **书写步骤**：
  1. 写：写出化学方程式
  2. 拆：易溶强电解质拆成离子
  3. 删：删去两边相同离子
  4. 查：检查原子守恒、电荷守恒

- **不能拆的物质**：
  - 难溶物（BaSO₄、AgCl、CaCO₃）
  - 弱电解质（CH₃COOH、NH₃·H₂O）
  - 气体（CO₂、NH₃、Cl₂）
  - 氧化物（H₂O、SO₂）

### 2.2 离子共存
- **不能共存的情况**：
  - 生成沉淀：Ag⁺ + Cl⁻、Ba²⁺ + SO₄²⁻
  - 生成气体：H⁺ + CO₃²⁻、H⁺ + HCO₃⁻
  - 生成弱电解质：H⁺ + OH⁻、H⁺ + CH₃COO⁻
  - 发生氧化还原：Fe³⁺ + I⁻、MnO₄⁻ + Fe²⁺

## 第三章 氧化还原反应

### 3.1 基本概念
- **氧化反应**：失电子，化合价升高
- **还原反应**：得电子，化合价降低
- **氧化剂**：得电子的物质（被还原）
- **还原剂**：失电子的物质（被氧化）

### 3.2 配平方法
- **化合价升降法**：
  1. 标化合价
  2. 找变化
  3. 求最小公倍数
  4. 配系数
  5. 检查守恒

### 3.3 常见氧化剂和还原剂
- **氧化剂**：O₂、Cl₂、浓H₂SO₄、HNO₃、KMnO₄、Fe³⁺
- **还原剂**：活泼金属、H₂、C、CO、SO₂、Fe²⁺、I⁻

## 第四章 金属及其化合物

### 4.1 钠及其化合物
- **钠的性质**：
  - 与O₂：4Na + O₂ = 2Na₂O（常温）
  - 与H₂O：2Na + 2H₂O = 2NaOH + H₂↑
  - 保存：煤油或石蜡油中

- **Na₂O₂（过氧化钠）**：
  - 与H₂O：2Na₂O₂ + 2H₂O = 4NaOH + O₂↑
  - 与CO₂：2Na₂O₂ + 2CO₂ = 2Na₂CO₃ + O₂
  - 用途：供氧剂、漂白剂

### 4.2 铝及其化合物
- **铝的两性**：
  - 与酸：2Al + 6HCl = 2AlCl₃ + 3H₂↑
  - 与碱：2Al + 2NaOH + 2H₂O = 2NaAlO₂ + 3H₂↑

- **Al(OH)₃的两性**：
  - 与酸：Al(OH)₃ + 3HCl = AlCl₃ + 3H₂O
  - 与碱：Al(OH)₃ + NaOH = NaAlO₂ + 2H₂O

### 4.3 铁及其化合物
- **Fe²⁺与Fe³⁺的转化**：
  - Fe²⁺ → Fe³⁺：加氧化剂（Cl₂、HNO₃）
  - Fe³⁺ → Fe²⁺：加还原剂（Fe、Cu）

- **Fe(OH)₂的制备**：
  - FeSO₄ + 2NaOH = Fe(OH)₂↓ + Na₂SO₄
  - 现象：白色沉淀迅速变灰绿最后变红褐色

## 第五章 非金属及其化合物

### 5.1 氯及其化合物
- **Cl₂的性质**：
  - 与H₂：H₂ + Cl₂ = 2HCl（光照爆炸）
  - 与H₂O：Cl₂ + H₂O ⇌ HCl + HClO
  - 与碱：Cl₂ + 2NaOH = NaCl + NaClO + H₂O

- **HClO（次氯酸）**：
  - 弱酸性、强氧化性
  - 漂白原理：氧化有色物质
  - 不稳定：2HClO = 2HCl + O₂↑（光照）

### 5.2 硫及其化合物
- **SO₂的性质**：
  - 酸性氧化物：SO₂ + 2NaOH = Na₂SO₃ + H₂O
  - 还原性：SO₂ + Cl₂ + 2H₂O = H₂SO₄ + 2HCl
  - 漂白性：与有色物质化合（可逆）

- **H₂SO₄的性质**：
  - 稀硫酸：强酸通性
  - 浓硫酸：吸水性、脱水性、强氧化性

### 5.3 氮及其化合物
- **NH₃的性质**：
  - 碱性：NH₃ + H₂O ⇌ NH₃·H₂O ⇌ NH₄⁺ + OH⁻
  - 与酸：NH₃ + HCl = NH₄Cl（白烟）
  - 还原性：4NH₃ + 5O₂ = 4NO + 6H₂O（催化氧化）

- **HNO₃的性质**：
  - 强氧化性：与金属反应不生成H₂
  - 不稳定：4HNO₃ = 4NO₂↑ + O₂↑ + 2H₂O（光照）

## 第六章 化学反应与能量

### 6.1 化学反应中的能量变化
- **放热反应**：燃烧、中和、活泼金属与酸
- **吸热反应**：大多数分解反应、C + CO₂、Ba(OH)₂·8H₂O + NH₄Cl

### 6.2 原电池
- **构成条件**：
  - 两种活泼性不同的金属（或金属与石墨）
  - 电解质溶液
  - 形成闭合回路

- **工作原理**：
  - 负极：活泼金属，失电子，氧化反应
  - 正极：不活泼金属，得电子，还原反应

## 易错点提醒

1. **离子方程式**：注意物质状态，沉淀、气体、弱电解质不拆
2. **氧化还原**：化合价升失氧化还原剂，降得还原氧化剂
3. **金属活动性**：Na > Mg > Al > Zn > Fe > Cu > Ag
4. **浓硫酸**：常温下可钝化Fe、Al
5. **NH₃与HCl**：产物是NH₄Cl固体（白烟），不是气体
