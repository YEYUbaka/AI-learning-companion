# 高一英语核心知识点

## 第一部分 核心语法

### 1.1 时态系统

**一般现在时**
- 用法：习惯动作、客观真理、现在状态
- 结构：do/does
- 标志词：always, usually, often, sometimes, every day

**一般过去时**
- 用法：过去发生的动作或状态
- 结构：did
- 标志词：yesterday, last week, ago, in 1990

**现在进行时**
- 用法：正在进行的动作
- 结构：am/is/are + doing
- 标志词：now, at present, look, listen

**过去进行时**
- 用法：过去某时刻正在进行的动作
- 结构：was/were + doing
- 标志词：at that time, at 8 yesterday

**现在完成时**
- 用法：过去发生对现在有影响，或从过去持续到现在
- 结构：have/has + done
- 标志词：already, yet, just, ever, never, since, for

**过去完成时**
- 用法：过去的过去
- 结构：had + done
- 标志词：by the time, before

### 1.2 被动语态

**基本结构**：be + done
- 一般现在时被动：am/is/are + done
- 一般过去时被动：was/were + done
- 现在完成时被动：have/has been + done
- 情态动词被动：can/must/should + be + done

**使用场合**：
- 不知道或不必说出动作执行者
- 强调动作承受者
- 客观说明事实

### 1.3 定语从句

**关系代词**：
- who/whom：指人
- which：指物
- that：指人或物
- whose：表所属关系

**关系副词**：
- when：时间
- where：地点
- why：原因

**限制性与非限制性**：
- 限制性：不用逗号，that可用
- 非限制性：用逗号，不用that

### 1.4 名词性从句

**主语从句**：
- That he will come is certain.
- It is certain that he will come.（形式主语）

**宾语从句**：
- I think (that) he is right.
- 注意时态呼应

**表语从句**：
- The problem is that we lack money.

**同位语从句**：
- The news that he won the prize is true.

### 1.5 状语从句

**时间状语从句**：when, while, as, before, after, since, until
**条件状语从句**：if, unless, as long as
**原因状语从句**：because, since, as
**让步状语从句**：although, though, even if
**结果状语从句**：so...that, such...that
**目的状语从句**：so that, in order that

## 第二部分 核心词汇

### 2.1 高频动词短语

**come系列**：
- come across 偶遇
- come up 走近；被提出
- come up with 想出
- come about 发生

**get系列**：
- get along/on with 与...相处
- get through 通过；接通电话
- get over 克服
- get down to 开始认真做

**take系列**：
- take off 起飞；脱下；成功
- take on 承担；呈现
- take over 接管
- take up 占据；开始从事

**put系列**：
- put forward 提出
- put off 推迟
- put up 张贴；搭建；提供住宿
- put up with 忍受

### 2.2 重点名词

**抽象名词**：
- advice 建议（不可数）
- information 信息（不可数）
- progress 进步（不可数）
- furniture 家具（不可数）

**易混名词**：
- affect (v.) 影响 / effect (n.) 影响；效果
- practice (n.) 练习 / practise (v.) 练习
- advice (n.) 建议 / advise (v.) 建议

### 2.3 重点形容词/副词

**-ed / -ing 形容词**：
- interested / interesting
- excited / exciting
- bored / boring
- tired / tiring

**比较级特殊用法**：
- the + 比较级, the + 比较级（越...越...）
- 比较级 + and + 比较级（越来越...）

## 第三部分 句型结构

### 3.1 强调句型
- It is/was + 被强调部分 + that/who + 其他
- 判断方法：去掉 It is/was...that 后句子完整

### 3.2 倒装句型

**完全倒装**：
- Here comes the bus.
- There stands a tree.

**部分倒装**：
- Never have I seen such a beautiful place.
- Only then did I realize my mistake.
- Not only...but also...

### 3.3 虚拟语气

**if条件句**：
- 与现在相反：If + 过去式, would/could/might + do
- 与过去相反：If + had done, would/could/might + have done
- 与将来相反：If + should/were to do, would/could/might + do

**wish/as if**：
- 与现在相反：wish + 过去式
- 与过去相反：wish + had done

## 第四部分 写作技巧

### 4.1 书信格式

**开头**：
- Dear Sir/Madam,
- Dear Mr./Ms. + 姓,

**结尾**：
- Yours sincerely, / Yours faithfully,
- Best wishes, / Best regards,

### 4.2 常用连接词

**表递进**：besides, moreover, furthermore, in addition
**表转折**：however, nevertheless, on the contrary
**表因果**：therefore, thus, as a result, consequently
**表总结**：in conclusion, in summary, to sum up

### 4.3 高级句式

**非谓语动词**：
- Seeing the teacher, the students stood up.
- The book written by Mo Yan is popular.

**with复合结构**：
- With so much work to do, I can't go out.

**独立主格**：
- Weather permitting, we'll go hiking.

## 易错点提醒

1. **主谓一致**：集体名词、不定代词、分数百分数作主语
2. **冠词**：a/an/the的区别，零冠词的使用
3. **介词**：时间介词in/on/at，地点介词in/on/at
4. **词性转换**：注意动词、名词、形容词、副词的转换
5. **固定搭配**：动词短语、介词短语要牢记
