# 高一历史核心知识点

## 第一单元 古代中国的政治制度

### 1.1 夏商周的政治制度
- **夏朝**：中国第一个王朝，王位世袭制代替禅让制
- **商朝**：内外服制度，神权与王权结合
- **西周**：
  - 分封制：周天子分封诸侯，层层分封
  - 宗法制：嫡长子继承制，大宗与小宗
  - 礼乐制度：维护等级秩序

### 1.2 秦朝中央集权制度
- **皇帝制度**：皇帝独尊，集权于一身
- **三公九卿**：
  - 三公：丞相（行政）、太尉（军事）、御史大夫（监察）
  - 九卿：具体事务官员
- **郡县制**：中央直接管理地方
- **意义**：奠定中国古代政治制度基本格局

### 1.3 汉到元政治制度的演变
- **汉朝**：
  - 中外朝制度：削弱相权
  - 刺史制度：监察地方
  - 推恩令：削弱诸侯王势力

- **隋唐**：
  - 三省六部制：中书省（决策）、门下省（审议）、尚书省（执行）
  - 科举制：分科考试选拔官员

- **宋朝**：
  - 集权措施：收兵权、财权、行政权
  - 文官政治：重文轻武

- **元朝**：
  - 行省制度：地方行政区划
  - 宣政院：管理西藏

### 1.4 明清君主专制的加强
- **明朝**：
  - 废丞相：权分六部
  - 设内阁：票拟制度
  - 厂卫特务机构：加强监察

- **清朝**：
  - 军机处：提高行政效率，君主专制达到顶峰
  - 文字狱：加强思想控制

## 第二单元 古代中国经济的基本结构与特点

### 2.1 农业
- **耕作方式**：刀耕火种 → 石器锄耕 → 铁犁牛耕
- **土地制度**：
  - 井田制（西周）：土地国有
  - 封建土地私有制（战国后）
- **农业技术**：
  - 春秋战国：铁农具、牛耕
  - 汉代：耧车、代田法
  - 唐代：曲辕犁、筒车

### 2.2 手工业
- **经营形态**：
  - 官营手工业：政府直接经营
  - 民营手工业：民间私人经营
  - 家庭手工业：农户副业
- **成就**：
  - 冶铁：春秋战国铁器普及
  - 制瓷：唐三彩、宋代五大名窑
  - 纺织：丝织业发达

### 2.3 商业
- **商业发展**：
  - 春秋战国：商业繁荣
  - 唐代：草市、夜市
  - 宋代：打破市坊界限
  - 明清：商帮出现（晋商、徽商）
- **政策**：重农抑商

### 2.4 经济政策
- **重农抑商**：
  - 原因：维护专制统治，保证财政收入
  - 影响：农业发展，商业受限
- **海禁政策**：
  - 明清：严格限制对外贸易
  - 影响：阻碍资本主义萌芽发展

## 第三单元 近代中国反侵略、求民主的潮流

### 3.1 鸦片战争
- **背景**：英国完成工业革命，需要打开中国市场
- **过程**：1840-1842年
- **结果**：《南京条约》
  - 割香港岛
  - 赔款2100万银元
  - 开放五口通商
  - 协定关税
- **影响**：中国开始沦为半殖民地半封建社会

### 3.2 太平天国运动
- **背景**：民族矛盾、阶级矛盾激化
- **过程**：
  - 1851年金田起义
  - 1853年定都天京
  - 《天朝田亩制度》：平均分配土地
  - 《资政新篇》：发展资本主义
- **失败原因**：农民阶级局限性

### 3.3 洋务运动
- **时间**：19世纪60-90年代
- **口号**：自强、求富
- **内容**：
  - 军事工业：江南制造总局
  - 民用工业：轮船招商局
  - 新式教育：京师同文馆
- **评价**：未使中国富强，但引进西方技术

### 3.4 甲午中日战争
- **时间**：1894-1895年
- **结果**：《马关条约》
  - 割辽东半岛、台湾、澎湖列岛
  - 赔款2亿两白银
  - 开放通商口岸
  - 允许日本在华设厂
- **影响**：大大加深中国半殖民地化程度

### 3.5 戊戌变法
- **背景**：民族危机加深，资产阶级维新思想传播
- **时间**：1898年（百日维新）
- **内容**：政治、经济、军事、教育改革
- **失败**：慈禧太后发动政变
- **意义**：思想启蒙作用

### 3.6 义和团运动与八国联军侵华
- **义和团**：反帝爱国运动
- **八国联军**：1900年侵华
- **《辛丑条约》**：
  - 赔款4.5亿两白银
  - 划定使馆界
  - 拆毁大沽炮台
  - 严禁反帝活动
- **影响**：中国完全沦为半殖民地半封建社会

### 3.7 辛亥革命
- **背景**：民族资本主义发展，资产阶级革命思想传播
- **过程**：
  - 1905年同盟会成立
  - 1911年武昌起义
  - 1912年中华民国成立
- **成果**：
  - 推翻清朝统治
  - 结束君主专制制度
  - 建立共和国
- **局限**：未改变半殖民地半封建社会性质

## 易错点提醒

1. **分封制与郡县制**：分封制是地方分权，郡县制是中央集权
2. **三省六部**：相权一分为三，加强皇权
3. **科举制**：隋朝创立，唐朝完善，清末废除
4. **重农抑商**：不是不发展商业，而是限制商人地位
5. **半殖民地半封建社会**：鸦片战争后开始，《辛丑条约》后完全形成
