# 高二下册生物核心知识点

## 第一章 基因工程

### 1.1 基因工程的原理
**概念**：按照人们的意愿，把一种生物的某种基因提取出来，加以修饰改造后，放到另一种生物的细胞里

**工具**：
- 基因的剪刀：限制性核酸内切酶
- 基因的针线：DNA连接酶
- 基因的运输工具：载体（质粒）

### 1.2 基因工程的步骤
1. 目的基因的获取
2. 基因表达载体的构建
3. 将目的基因导入受体细胞
4. 目的基因的检测与鉴定

### 1.3 基因工程的应用
- 转基因植物：抗虫、抗病、抗除草剂
- 转基因动物：生产药物蛋白
- 转基因微生物：生产胰岛素

## 第二章 细胞工程

### 2.1 植物细胞工程
**植物组织培养**：
- 原理：细胞全能性
- 过程：离体植物组织 → 愈伤组织 → 试管苗 → 植株

**植物体细胞杂交**：
- 原理：细胞膜的流动性、细胞全能性
- 过程：去壁 → 融合 → 培养

### 2.2 动物细胞工程
**动物细胞培养**：
- 原理：细胞增殖
- 条件：无菌、无毒、营养、温度、pH、气体

**单克隆抗体**：
- 原理：细胞融合
- 过程：B淋巴细胞 + 骨髓瘤细胞 → 杂交瘤细胞

**核移植技术**：
- 克隆动物
- 胚胎干细胞

## 第三章 胚胎工程

### 3.1 体外受精
**过程**：
- 采集卵母细胞
- 采集精子
- 体外受精

### 3.2 胚胎移植
**过程**：
- 供体：超数排卵
- 受体：同期发情
- 胚胎移植

### 3.3 胚胎分割与胚胎干细胞
**胚胎分割**：产生同卵双胎或多胎

**胚胎干细胞**：
- 来源：早期胚胎
- 特点：全能性

## 易错提醒

1. 限制酶识别特定序列并切割
2. DNA连接酶连接磷酸二酯键
3. 植物组织培养依据细胞全能性
4. 动物细胞培养需要CO₂培养箱
5. 胚胎移植需要同期发情
