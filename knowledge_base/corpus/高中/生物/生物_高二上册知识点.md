# 高二上册生物核心知识点

## 第一章 遗传的分子基础

### 1.1 DNA是主要的遗传物质
**证据**：
- 肺炎双球菌转化实验
- 噬菌体侵染细菌实验

### 1.2 DNA的结构
**双螺旋结构**：
- 两条链反向平行
- 外侧：脱氧核糖-磷酸骨架
- 内侧：碱基对（A-T，G-C）

**碱基互补配对原则**：A=T，G≡C

### 1.3 DNA的复制
**时期**：有丝分裂间期、减数第一次分裂间期

**特点**：
- 半保留复制
- 边解旋边复制

**条件**：模板、原料、能量、酶

### 1.4 基因的表达
**转录**：DNA → mRNA
- 场所：细胞核
- 原则：碱基互补配对（A-U，T-A，G-C，C-G）

**翻译**：mRNA → 蛋白质
- 场所：核糖体
- 密码子：mRNA上决定一个氨基酸的三个相邻碱基

## 第二章 基因突变与基因重组

### 2.1 基因突变
**概念**：DNA分子中碱基对的增添、缺失或替换

**特点**：
- 普遍性、随机性
- 低频性、不定向性

**意义**：生物变异的根本来源

### 2.2 基因重组
**类型**：
- 自由组合：非同源染色体上非等位基因重组
- 交叉互换：同源染色体非姐妹染色单体交叉互换

**时期**：减数第一次分裂

### 2.3 染色体变异
**数目变异**：
- 个别增减：21三体综合征
- 成倍增减：多倍体

**结构变异**：缺失、重复、倒位、易位

## 第三章 生物的进化

### 3.1 现代生物进化理论
**核心**：自然选择学说

**基本观点**：
- 种群是生物进化的基本单位
- 突变和基因重组提供原材料
- 自然选择决定进化方向
- 隔离导致物种形成

### 3.2 种群基因频率
**基因频率**：某基因占全部等位基因的比例

**计算**：
- 基因型频率法
- 基因型个体数法

### 3.3 物种形成
**隔离**：
- 地理隔离
- 生殖隔离（物种形成的标志）

**过程**：突变和基因重组 → 自然选择 → 隔离 → 新物种

## 易错提醒

1. DNA复制是半保留复制
2. 转录在细胞核，翻译在核糖体
3. 基因突变不定向，自然选择定向
4. 生殖隔离是物种形成的标志
5. 种群是生物进化的基本单位
