# 高一生物核心知识点

## 第一章 走近细胞

### 1.1 细胞是生命活动的基本单位
- **生命系统的结构层次**：细胞 → 组织 → 器官 → 系统 → 个体 → 种群 → 群落 → 生态系统 → 生物圈
- **病毒**：无细胞结构，由蛋白质外壳和内部核酸组成

### 1.2 原核细胞与真核细胞
- **原核细胞**：无核膜，无成形细胞核（细菌、蓝藻、放线菌）
- **真核细胞**：有核膜，有成形细胞核（动物、植物、真菌）
- **共同点**：都有细胞膜、细胞质、核糖体

## 第二章 组成细胞的分子

### 2.1 组成细胞的元素
- **大量元素**：C、H、O、N、P、S、K、Ca、Mg（9种）
- **微量元素**：Fe、Mn、Zn、Cu、B、Mo（6种）
- **最基本元素**：C
- **主要元素**：C、H、O、N、P、S

### 2.2 无机物
- **水**：
  - 自由水：良好溶剂，参与代谢
  - 结合水：细胞结构组成成分
- **无机盐**：以离子形式存在，维持渗透压、酸碱平衡

### 2.3 有机物

**糖类**：
- 单糖：葡萄糖、果糖、核糖、脱氧核糖
- 二糖：蔗糖、麦芽糖、乳糖
- 多糖：淀粉、纤维素（植物）、糖原（动物）

**脂质**：
- 脂肪：储能
- 磷脂：构成细胞膜
- 固醇：胆固醇、性激素、维生素D

**蛋白质**：
- 基本单位：氨基酸（20种）
- 结构通式：NH₂-C-COOH（R基不同）
- 肽键：-CO-NH-
- 功能：结构、催化、运输、调节、免疫

**核酸**：
- DNA：脱氧核糖核酸，遗传信息载体
- RNA：核糖核酸，蛋白质合成
- 基本单位：核苷酸

## 第三章 细胞的基本结构

### 3.1 细胞膜
- **组成**：磷脂双分子层、蛋白质、糖类
- **结构特点**：流动性
- **功能特点**：选择透过性
- **功能**：保护、物质交换、信息交流

### 3.2 细胞器

**线粒体**：
- 有氧呼吸主要场所
- 双层膜，有少量DNA和RNA

**叶绿体**：
- 光合作用场所
- 双层膜，有少量DNA和RNA

**内质网**：
- 蛋白质合成和加工
- 脂质合成

**高尔基体**：
- 蛋白质加工、分类、包装
- 植物细胞壁形成

**核糖体**：
- 蛋白质合成场所
- 无膜结构

**中心体**：
- 与细胞分裂有关
- 动物和低等植物有

### 3.3 细胞核
- **核膜**：双层膜，有核孔
- **染色质**：DNA + 蛋白质
- **核仁**：与核糖体形成有关
- **功能**：遗传信息库，代谢和遗传中心

## 第四章 细胞的物质输入和输出

### 4.1 物质跨膜运输方式

**自由扩散**：
- 顺浓度梯度
- 不耗能，不需载体
- 例：O₂、CO₂、H₂O、甘油、乙醇

**协助扩散**：
- 顺浓度梯度
- 不耗能，需载体
- 例：葡萄糖进入红细胞

**主动运输**：
- 逆浓度梯度
- 耗能，需载体
- 例：小肠吸收葡萄糖、氨基酸

### 4.2 渗透作用
- **条件**：半透膜、浓度差
- **植物细胞吸水失水**：
  - 原生质层 = 细胞膜 + 液泡膜 + 两层膜之间的细胞质
  - 质壁分离：外界溶液浓度 > 细胞液浓度
  - 质壁分离复原：清水浸泡

## 第五章 细胞的能量供应和利用

### 5.1 ATP
- **结构**：A-P~P~P（腺苷三磷酸）
- **功能**：直接能源物质
- **转化**：ATP ⇌ ADP + Pi + 能量

### 5.2 酶
- **本质**：大多数是蛋白质，少数是RNA
- **特性**：高效性、专一性、作用条件温和
- **影响因素**：温度、pH

### 5.3 光合作用

**场所**：叶绿体
**总反应式**：6CO₂ + 6H₂O → C₆H₁₂O₆ + 6O₂（光能）

**光反应**（类囊体薄膜）：
- 水的光解：2H₂O → 4[H] + O₂
- ATP生成：ADP + Pi → ATP

**暗反应**（叶绿体基质）：
- CO₂固定：CO₂ + C₅ → 2C₃
- C₃还原：2C₃ + [H] + ATP → (CH₂O) + C₅

**影响因素**：光照强度、CO₂浓度、温度

### 5.4 细胞呼吸

**有氧呼吸**：
- 场所：细胞质基质 + 线粒体
- 反应式：C₆H₁₂O₆ + 6O₂ → 6CO₂ + 6H₂O + 大量能量（38ATP）

**无氧呼吸**：
- 场所：细胞质基质
- 产物：乳酸或酒精 + CO₂
- 能量：少量（2ATP）

## 第六章 细胞的生命历程

### 6.1 细胞增殖

**有丝分裂**：
- 间期：DNA复制、蛋白质合成
- 前期：染色质 → 染色体，核膜核仁消失，纺锤体出现
- 中期：染色体排列在赤道板（观察染色体最佳时期）
- 后期：着丝点分裂，染色体数目加倍
- 末期：染色体 → 染色质，核膜核仁重现，细胞板 → 细胞壁

**特点**：
- 染色体复制一次，细胞分裂一次
- 遗传物质平均分配

### 6.2 细胞分化
- **概念**：形态、结构、功能发生稳定性差异
- **特点**：持久性、不可逆性、普遍性
- **实质**：基因选择性表达

### 6.3 细胞衰老和凋亡
- **衰老特征**：代谢减慢、色素积累、酶活性降低、核体积增大
- **凋亡**：细胞自动结束生命（程序性死亡）
- **意义**：维持内部环境稳定

### 6.4 细胞癌变
- **原因**：原癌基因激活、抑癌基因失活
- **特征**：无限增殖、形态改变、易扩散转移

## 易错点提醒

1. **原核生物**：蓝藻是原核生物，能光合作用但无叶绿体
2. **ATP**：直接能源物质，不是主要能源物质（糖类）
3. **光合作用**：O₂来自水的光解，不是CO₂
4. **有丝分裂**：染色体数目加倍在后期，DNA加倍在间期
5. **细胞分化**：不可逆，但全能性未丧失
