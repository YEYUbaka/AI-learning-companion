# 高一地理核心知识点

## 第一章 行星地球

### 1.1 宇宙中的地球
- **天体系统层次**：地月系 → 太阳系 → 银河系 → 总星系
- **太阳系八大行星**：水金地火木土天海
- **地球存在生命的条件**：
  - 稳定的光照条件
  - 安全的宇宙环境
  - 适宜的温度
  - 液态水
  - 适合生物呼吸的大气

### 1.2 太阳对地球的影响
- **太阳辐射**：
  - 能量来源：核聚变反应
  - 影响：光热资源、气候、水循环
- **太阳活动**：
  - 标志：黑子（光球层）、耀斑（色球层）
  - 周期：11年
  - 影响：磁暴、极光、无线电短波通讯中断

### 1.3 地球的运动

**自转**：
- 方向：自西向东
- 周期：1个恒星日（23时56分4秒）
- 速度：角速度15°/时，线速度赤道最大
- 地理意义：
  - 昼夜更替
  - 地方时差异
  - 水平运动物体偏转（北右南左）

**公转**：
- 方向：自西向东
- 周期：1个恒星年（365日6时9分10秒）
- 轨道：椭圆，近日点1月初，远日点7月初
- 黄赤交角：23°26'
- 地理意义：
  - 昼夜长短变化
  - 正午太阳高度变化
  - 四季更替
  - 五带划分

### 1.4 地球的圈层结构

**内部圈层**：
- 地壳：莫霍界面以上
- 地幔：莫霍界面至古登堡界面
- 地核：古登堡界面以下

**外部圈层**：
- 大气圈
- 水圈
- 生物圈

## 第二章 地球上的大气

### 2.1 大气的组成和垂直分层
- **组成**：氮78%、氧21%、其他1%
- **分层**：
  - 对流层：天气现象，气温随高度降低
  - 平流层：臭氧层，气温随高度升高
  - 高层大气：电离层反射无线电波

### 2.2 大气的热力作用
- **大气对太阳辐射的削弱**：吸收、反射、散射
- **大气对地面的保温作用**：
  - 大气逆辐射：保温作用
  - 温室效应：CO₂等温室气体增多

### 2.3 大气运动

**热力环流**：
- 原理：冷热不均引起空气垂直运动
- 规律：热上升冷下沉，高压流向低压

**大气环流**：
- 三圈环流：低纬、中纬、高纬环流圈
- 气压带风带：
  - 赤道低气压带：上升气流，多雨
  - 副热带高气压带：下沉气流，少雨
  - 副极地低气压带：上升气流，多雨
  - 极地高气压带：下沉气流，少雨
- 季风环流：
  - 东亚季风：冬季西北风，夏季东南风
  - 南亚季风：冬季东北风，夏季西南风

### 2.4 常见天气系统
- **锋面系统**：
  - 冷锋：冷气团主动移动（我国冬季）
  - 暖锋：暖气团主动移动
- **气旋与反气旋**：
  - 气旋：低压中心，上升气流，多阴雨
  - 反气旋：高压中心，下沉气流，晴朗

## 第三章 地球上的水

### 3.1 水循环
- **类型**：海陆间循环、陆地内循环、海上内循环
- **环节**：蒸发、水汽输送、降水、径流
- **意义**：水资源更新、联系四大圈层、塑造地表形态

### 3.2 洋流
- **成因**：盛行风、陆地形状、地转偏向力
- **分布规律**：
  - 中低纬：反气旋型（北顺南逆）
  - 中高纬：气旋型（北逆南顺）
  - 北印度洋：冬逆夏顺
- **影响**：
  - 气候：暖流增温增湿，寒流降温减湿
  - 渔场：寒暖流交汇、上升流
  - 航海：顺流快，逆流慢
  - 污染：扩散污染

## 第四章 地表形态的塑造

### 4.1 营造地表形态的力量

**内力作用**：
- 地壳运动：水平运动（褶皱山系）、垂直运动（海陆变迁）
- 岩浆活动：火山、岩浆岩
- 地震：板块边界

**外力作用**：
- 风化：岩石破碎
- 侵蚀：流水、风力、冰川、海浪
- 搬运：流水、风力
- 沉积：三角洲、沙丘
- 固结成岩：沉积岩

### 4.2 山地的形成
- **褶皱山**：岩层弯曲变形（喜马拉雅山）
- **断块山**：岩层断裂（华山、庐山）
- **火山**：岩浆喷发（富士山）

### 4.3 河流地貌
- **侵蚀地貌**：V型谷、峡谷
- **堆积地貌**：冲积平原、三角洲

## 第五章 自然地理环境的整体性与差异性

### 5.1 自然地理环境的整体性
- **组成要素**：地形、气候、水文、土壤、生物
- **相互作用**：相互联系、相互制约、相互渗透
- **整体性表现**：
  - 地理要素间相互作用
  - 某一要素变化导致整体变化

### 5.2 自然地理环境的差异性
- **地域分异规律**：
  - 纬度地带性：热量差异（赤道→两极）
  - 经度地带性：水分差异（沿海→内陆）
  - 垂直地带性：海拔差异（山麓→山顶）
  - 非地带性：地形、洋流等

## 易错点提醒

1. **地球自转与公转**：自转产生昼夜更替，公转产生四季变化
2. **太阳高度角**：正午太阳高度角最大，不是90°
3. **气压带风带**：随太阳直射点移动而移动
4. **洋流分布**：北半球顺时针，南半球逆时针（中低纬）
5. **地域分异**：纬度地带性看热量，经度地带性看水分
