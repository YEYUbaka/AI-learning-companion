# 高二下册物理核心知识点

## 第一章 电磁感应

### 1.1 电磁感应现象
**法拉第电磁感应定律**：
E = nΔΦ/Δt = BLv

**楞次定律**：
感应电流的磁场总是阻碍引起感应电流的磁通量的变化

**判断方法**：
- 增反减同
- 来拒去留

### 1.2 感应电动势
**导体切割磁感线**：
E = BLv sin θ

**线圈转动**：
E = nBSω sin ωt

**自感**：
E自 = LΔI/Δt

### 1.3 电磁感应中的能量转化
**焦耳热**：Q = I²Rt

**功率**：P = F·v = BILv

**能量守恒**：
外力做功 = 焦耳热 + 动能增量

## 第二章 交流电

### 2.1 交流电的产生
**正弦交流电**：
e = Em sin ωt = nBSω sin ωt

**有效值**：
E = Em/√2，I = Im/√2，U = Um/√2

### 2.2 交流电的四值
**瞬时值**：某一时刻的值
**最大值**：Em = nBSω
**有效值**：E = Em/√2（计算功率、热量）
**平均值**：Ē = nΔΦ/Δt（计算电量）

### 2.3 变压器
**理想变压器**：
- 电压关系：U₁/U₂ = n₁/n₂
- 电流关系：I₁/I₂ = n₂/n₁
- 功率关系：P₁ = P₂

**远距离输电**：
- 输电损耗：ΔP = I²R
- 降低损耗：提高电压

## 第三章 光学

### 3.1 光的折射
**折射定律**：
n₁ sin θ₁ = n₂ sin θ₂

**折射率**：
n = c/v = sin θ₁/sin θ₂

### 3.2 全反射
**临界角**：sin C = 1/n

**条件**：
- 光从光密介质射向光疏介质
- 入射角大于临界角

### 3.3 光的干涉
**双缝干涉**：
Δx = Lλ/d
- L：屏到双缝距离
- d：双缝间距
- λ：波长

**薄膜干涉**：
- 等厚干涉
- 增透膜、增反膜

### 3.4 光的衍射
**单缝衍射**：
- 中央亮纹最宽最亮
- 缝越窄，衍射越明显

**圆孔衍射**：
- 泊松亮斑

### 3.5 光的偏振
**偏振光**：只在某一方向振动的光

**应用**：偏振片、立体电影

## 第四章 原子物理初步

### 4.1 光电效应
**规律**：
- 存在截止频率
- 光电子最大初动能与光强无关
- 瞬时性

**光电效应方程**：
Ek = hν - W₀

### 4.2 波粒二象性
**光子能量**：E = hν

**光子动量**：p = h/λ

**德布罗意波长**：λ = h/p

## 易错提醒

1. 楞次定律判断感应电流方向
2. 交流电有效值用于计算功率和热量
3. 平均值用于计算电量
4. 变压器只能改变交流电压
5. 全反射条件：光密→光疏，θ > C
6. 光电效应中光强影响光电流，不影响最大初动能
