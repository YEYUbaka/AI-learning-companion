# 高二上册物理核心知识点

## 第一章 静电场

### 1.1 电荷与库仑定律
**电荷守恒定律**：电荷既不能创造，也不能消灭，只能转移

**元电荷**：e = 1.6×10⁻¹⁹ C

**库仑定律**：F = kq₁q₂/r²
- k = 9.0×10⁹ N·m²/C²
- 适用条件：真空中的点电荷

### 1.2 电场强度
**定义式**：E = F/q（试探电荷受力与电荷量的比值）

**点电荷场强**：E = kQ/r²

**匀强电场**：E = U/d

**电场线**：
- 切线方向为场强方向
- 疏密表示场强大小
- 不相交、不闭合

### 1.3 电势与电势差
**电势φ**：描述电场能量性质的物理量

**电势差U**：UAB = φA - φB

**电场力做功**：WAB = qUAB

**等势面**：
- 电势相等的点构成的面
- 与电场线垂直
- 沿电场线方向电势降低

### 1.4 电势能
**定义**：Ep = qφ

**电场力做功与电势能变化**：
WAB = EpA - EpB = -ΔEp

### 1.5 带电粒子在电场中的运动
**加速**：
qU = ½mv² - ½mv₀²

**偏转**（类平抛运动）：
- 水平方向：x = v₀t
- 竖直方向：y = ½at²，a = qE/m

**偏转角**：tan θ = vy/v₀

### 1.6 电容器
**电容定义**：C = Q/U

**平行板电容器**：C = εS/(4πkd)
- ε：介电常数
- S：正对面积
- d：板间距离

**电容器充放电**：
- 充电：Q↑，U↑，E↑
- 放电：Q↓，U↓，E↓

## 第二章 磁场

### 2.1 磁感应强度
**定义式**：B = F/(IL)（电流与磁场垂直）

**单位**：特斯拉（T），1T = 1N/(A·m)

**磁感线**：
- 闭合曲线
- 切线方向为磁场方向
- 疏密表示磁场强弱

### 2.2 安培定则
**直线电流**：右手握导线，大拇指指向电流，四指指向磁场

**环形电流**：右手握线圈，四指指向电流，大拇指指向磁场

**通电螺线管**：右手握螺线管，四指指向电流，大拇指指向N极

### 2.3 安培力
**公式**：F = BIL sin θ
- θ为B与I的夹角
- 垂直时：F = BIL

**左手定则**：
- 磁感线穿过手心
- 四指指向电流方向
- 大拇指指向安培力方向

### 2.4 洛伦兹力
**公式**：f = qvB sin θ
- 垂直时：f = qvB

**特点**：
- 永远不做功
- 只改变速度方向，不改变速度大小

**左手定则**：
- 磁感线穿过手心
- 四指指向正电荷运动方向（负电荷相反）
- 大拇指指向洛伦兹力方向

### 2.5 带电粒子在磁场中的运动
**匀速圆周运动**：
qvB = mv²/R

**半径**：R = mv/(qB)

**周期**：T = 2πm/(qB)（与速度无关）

**几何关系**：
- 圆心：垂直于速度方向
- 半径：利用几何关系求解
- 偏转角：圆心角 = 2×弦切角

## 易错提醒

1. 电场力做功与路径无关，只与初末位置有关
2. 电势是标量，但有正负
3. 等势面与电场线垂直
4. 洛伦兹力不做功
5. 带电粒子在磁场中做圆周运动，周期与速度无关
6. 左手定则判断力的方向，右手定则判断磁场方向
