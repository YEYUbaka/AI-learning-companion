# 高一物理核心知识点

## 第一章 运动的描述

### 1.1 质点、参考系和坐标系
- **质点**：用来代替物体的有质量的点（理想化模型）
- **参考系**：描述物体运动时选定的参照物体
- **坐标系**：建立在参考系上的定量描述位置的数学工具

### 1.2 时间和位移
- **时刻与时间间隔**：时刻对应位置，时间间隔对应过程
- **路程与位移**：
  - 路程：标量，运动轨迹的长度
  - 位移：矢量，从初位置指向末位置的有向线段
  - 公式：Δx = x₂ - x₁

### 1.3 速度
- **平均速度**：v̄ = Δx/Δt（矢量）
- **瞬时速度**：某一时刻的速度
- **速率**：瞬时速度的大小（标量）
- **平均速率**：路程/时间

### 1.4 加速度
- **定义**：a = Δv/Δt = (v - v₀)/t
- **物理意义**：描述速度变化快慢的物理量
- **方向**：与速度变化量Δv方向相同
- **注意**：加速度大不代表速度大

## 第二章 匀变速直线运动

### 2.1 基本公式
- **速度公式**：v = v₀ + at
- **位移公式**：x = v₀t + (1/2)at²
- **速度位移关系**：v² - v₀² = 2ax
- **平均速度**：v̄ = (v₀ + v)/2
- **中间时刻速度**：vₜ/₂ = (v₀ + v)/2

### 2.2 自由落体运动
- **条件**：只受重力，初速度为0
- **加速度**：g ≈ 10 m/s²（或9.8 m/s²）
- **公式**：
  - v = gt
  - h = (1/2)gt²
  - v² = 2gh

### 2.3 竖直上抛运动
- **特点**：初速度竖直向上，只受重力
- **上升阶段**：匀减速，a = -g
- **下降阶段**：自由落体
- **对称性**：上升和下降时间相等，速度大小相等

## 第三章 相互作用

### 3.1 重力
- **定义**：由于地球吸引而受到的力
- **大小**：G = mg
- **方向**：竖直向下
- **作用点**：重心

### 3.2 弹力
- **产生条件**：物体发生弹性形变
- **方向**：垂直于接触面，指向形变恢复方向
- **胡克定律**：F = kx（k为劲度系数，x为形变量）

### 3.3 摩擦力
- **静摩擦力**：
  - 条件：接触面粗糙，有相对运动趋势
  - 大小：0 < f ≤ fₘₐₓ（由平衡条件或牛顿定律求解）
  - 方向：与相对运动趋势方向相反

- **滑动摩擦力**：
  - 条件：接触面粗糙，有相对运动
  - 大小：f = μN（μ为动摩擦因数）
  - 方向：与相对运动方向相反

### 3.4 力的合成与分解
- **平行四边形定则**：两个力合成遵循平行四边形法则
- **正交分解法**：将力分解到x、y轴
  - Fₓ = F cos θ
  - Fᵧ = F sin θ
- **合力范围**：|F₁ - F₂| ≤ F合 ≤ F₁ + F₂

## 第四章 牛顿运动定律

### 4.1 牛顿第一定律
- **内容**：一切物体在不受外力或合外力为零时，保持静止或匀速直线运动
- **惯性**：物体保持原有运动状态的性质
- **质量**：惯性大小的唯一量度

### 4.2 牛顿第二定律
- **内容**：F合 = ma
- **矢量性**：力和加速度方向相同
- **瞬时性**：力和加速度同时产生、同时变化、同时消失
- **独立性**：每个力产生的加速度互不影响

### 4.3 牛顿第三定律
- **内容**：作用力与反作用力大小相等、方向相反、作用在不同物体上
- **特点**：同时产生、同时消失、同种性质

### 4.4 应用
- **连接体问题**：整体法、隔离法
- **超重与失重**：
  - 超重：a向上，F > G
  - 失重：a向下，F < G
  - 完全失重：a = g，F = 0

## 第五章 曲线运动

### 5.1 曲线运动的条件
- **速度方向**：沿轨迹切线方向
- **运动条件**：合外力与速度不在同一直线上
- **加速度方向**：指向轨迹凹侧

### 5.2 平抛运动
- **定义**：水平抛出，只受重力
- **性质**：水平方向匀速，竖直方向自由落体
- **公式**：
  - 水平：x = v₀t
  - 竖直：y = (1/2)gt²
  - 速度：vₓ = v₀，vᵧ = gt
  - 合速度：v = √(v₀² + (gt)²)

### 5.3 圆周运动
- **线速度**：v = s/t = 2πr/T
- **角速度**：ω = θ/t = 2π/T
- **关系**：v = ωr
- **向心加速度**：aₙ = v²/r = ω²r
- **向心力**：Fₙ = mv²/r = mω²r

## 第六章 机械能守恒定律

### 6.1 功
- **定义**：W = Fl cos θ
- **正负**：
  - θ < 90°：正功（动力）
  - θ > 90°：负功（阻力）
  - θ = 90°：不做功

### 6.2 功率
- **平均功率**：P̄ = W/t
- **瞬时功率**：P = Fv cos θ
- **额定功率**：机器正常工作的最大功率

### 6.3 动能定理
- **内容**：W合 = ΔEₖ = (1/2)mv² - (1/2)mv₀²
- **适用范围**：任何运动过程
- **解题优势**：只考虑初末状态，不考虑过程

### 6.4 机械能守恒定律
- **内容**：只有重力或弹力做功时，机械能守恒
- **表达式**：Eₖ₁ + Eₚ₁ = Eₖ₂ + Eₚ₂
- **判断条件**：
  - 只有重力做功
  - 除重力外其他力不做功
  - 除重力外其他力做功代数和为零

## 易错点提醒

1. **矢量与标量**：位移、速度、加速度、力是矢量，路程、速率、功、功率是标量
2. **受力分析**：按重力、弹力、摩擦力顺序，不要漏力或多力
3. **运动学公式**：只适用于匀变速直线运动
4. **牛顿第二定律**：F合是所有力的矢量和
5. **机械能守恒**：注意判断条件，不是所有问题都守恒
