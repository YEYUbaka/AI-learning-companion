# 勾股定理

勾股定理是初中数学中最重要的定理之一。

## 定理内容

在直角三角形中，两直角边的平方和等于斜边的平方。

**数学表达式**：a² + b² = c²

其中 a、b 是两条直角边，c 是斜边（最长边）。

## 典型例题

若直角三角形两直角边分别为 3 和 4，求斜边长度。

**解题过程**：
- a = 3, b = 4
- c² = 3² + 4² = 9 + 16 = 25
- c = 5

所以斜边长度为 **5**，这也是著名的勾三股四弦五。

## 逆定理

如果三角形三边满足 a² + b² = c²，则该三角形是直角三角形。
