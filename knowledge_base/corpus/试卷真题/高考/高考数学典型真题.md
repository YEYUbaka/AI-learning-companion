# 高考数学典型真题精选

## 一、选择题

### 题目1：集合运算
**题目**：已知集合A = {x | x² - 3x + 2 = 0}，B = {1, 2, 3}，则A ∩ B = ?
A. {1}  B. {2}  C. {1, 2}  D. {1, 2, 3}

**答案**：C

**解析**：
- 解方程x² - 3x + 2 = 0
- (x - 1)(x - 2) = 0
- x = 1 或 x = 2
- ∴ A = {1, 2}
- A ∩ B = {1, 2}

**考点**：集合的交集运算

---

### 题目2：复数运算
**题目**：若复数z满足(1 + i)z = 2，则|z| = ?
A. 1  B. √2  C. 2  D. 2√2

**答案**：B

**解析**：
- z = 2/(1 + i)
- = 2(1 - i)/[(1 + i)(1 - i)]
- = 2(1 - i)/2
- = 1 - i
- |z| = √(1² + (-1)²) = √2

**考点**：复数的除法、模的计算

---

### 题目3：函数性质
**题目**：函数f(x) = ln(x + 1) - ln(x - 1)的定义域为?
A. (-1, +∞)  B. (1, +∞)  C. (-∞, -1)∪(1, +∞)  D. R

**答案**：B

**解析**：
- 要使函数有意义，需满足：
- x + 1 > 0 且 x - 1 > 0
- x > -1 且 x > 1
- ∴ x > 1
- 定义域为(1, +∞)

**考点**：对数函数定义域

## 二、填空题

### 题目4：导数应用
**题目**：曲线y = x³ - 3x在点(1, -2)处的切线方程为_______

**答案**：y = -2

**解析**：
- y' = 3x² - 3
- 在点(1, -2)处，k = 3×1² - 3 = 0
- 切线方程：y - (-2) = 0(x - 1)
- y = -2

**考点**：导数的几何意义、切线方程

### 题目5：三角函数
**题目**：已知sin α + cos α = 1/2，则sin 2α = _______

**答案**：-3/4

**解析**：
- (sin α + cos α)² = 1/4
- sin²α + 2sin α cos α + cos²α = 1/4
- 1 + 2sin α cos α = 1/4
- 2sin α cos α = -3/4
- sin 2α = -3/4

**考点**：同角三角函数关系、二倍角公式

## 三、解答题

### 题目6：数列求和
**题目**：已知等差数列{aₙ}的前n项和为Sₙ，a₃ = 7，S₅ = 35。
(1) 求{aₙ}的通项公式；
(2) 求Sₙ。

**解答**：
(1) 设首项为a₁，公差为d
- a₃ = a₁ + 2d = 7  ①
- S₅ = 5a₁ + 10d = 35  ②
- 由②得：a₁ + 2d = 7
- 与①相同，说明d可以任意取值
- 由①：a₁ = 7 - 2d
- 由②：5(7 - 2d) + 10d = 35
- 35 - 10d + 10d = 35（恒成立）
- 取d = 2，则a₁ = 3
- aₙ = 3 + (n - 1)×2 = 2n + 1

(2) Sₙ = na₁ + n(n-1)d/2
- = 3n + n(n-1)
- = n² + 2n

**考点**：等差数列通项公式、前n项和

### 题目7：立体几何
**题目**：如图，在三棱锥P-ABC中，PA⊥平面ABC，AB⊥AC，PA = AB = AC = 2。
(1) 求证：平面PAB⊥平面PAC；
(2) 求三棱锥P-ABC的体积。

**解答**：
(1) 证明：
- ∵ PA⊥平面ABC
- ∴ PA⊥AC
- 又∵ AB⊥AC
- ∴ AC⊥平面PAB
- ∵ AC ⊂ 平面PAC
- ∴ 平面PAB⊥平面PAC

(2) V = (1/3)S△ABC × PA
- S△ABC = (1/2) × AB × AC = (1/2) × 2 × 2 = 2
- V = (1/3) × 2 × 2 = 4/3

**考点**：线面垂直、面面垂直、锥体体积

## 四、压轴题

### 题目8：解析几何
**题目**：已知椭圆C：x²/a² + y²/b² = 1 (a > b > 0)的离心率为√3/2，且过点(1, √3/2)。
(1) 求椭圆C的方程；
(2) 设直线l：y = kx + m与椭圆C交于A、B两点，O为坐标原点，若OA⊥OB，求证：点O到直线l的距离为定值。

**解答**：
(1) e = c/a = √3/2，∴ c² = 3a²/4
- b² = a² - c² = a²/4
- 将(1, √3/2)代入：1/a² + 3/(4b²) = 1
- 1/a² + 3/a² = 1
- a² = 4，b² = 1
- 椭圆方程：x²/4 + y² = 1

(2) 设A(x₁, y₁)，B(x₂, y₂)
- 联立y = kx + m与x²/4 + y² = 1
- x²/4 + (kx + m)² = 1
- (1 + 4k²)x² + 8kmx + 4m² - 4 = 0
- x₁ + x₂ = -8km/(1 + 4k²)
- x₁x₂ = (4m² - 4)/(1 + 4k²)

∵ OA⊥OB
- x₁x₂ + y₁y₂ = 0
- x₁x₂ + (kx₁ + m)(kx₂ + m) = 0
- (1 + k²)x₁x₂ + km(x₁ + x₂) + m² = 0
- (1 + k²)(4m² - 4)/(1 + 4k²) - 8k²m²/(1 + 4k²) + m² = 0
- 化简得：5m² = 4(1 + k²)
- m² = 4(1 + k²)/5

点O到直线l的距离：
- d = |m|/√(1 + k²) = 2/√5（定值）

**考点**：椭圆方程、直线与椭圆位置关系、韦达定理
