# 中考数学典型真题精选

## 一、选择题

### 题目1：实数运算
**题目**：计算：(-2)² + |3-5| - √9 = ?
A. 3  B. 5  C. 7  D. 9

**答案**：A

**解析**：
- (-2)² = 4
- |3-5| = |-2| = 2
- √9 = 3
- 原式 = 4 + 2 - 3 = 3

**考点**：实数的混合运算、绝对值、平方根

---

### 题目2：函数图像
**题目**：下列函数中，y随x增大而减小的是？
A. y = 2x + 1
B. y = -3x + 2
C. y = x²
D. y = 1/x (x > 0)

**答案**：B

**解析**：
- A：k = 2 > 0，递增
- B：k = -3 < 0，递减 ✓
- C：二次函数，在对称轴右侧递增
- D：反比例函数，k > 0时在每个象限内递减，但整体不单调

**考点**：一次函数性质、函数单调性

---

### 题目3：几何证明
**题目**：如图，AB是⊙O的直径，CD是弦，若∠BAC = 28°，则∠D = ?
A. 28°  B. 56°  C. 62°  D. 72°

**答案**：C

**解析**：
- ∵ AB是直径
- ∴ ∠ACB = 90°（直径所对圆周角是直角）
- ∴ ∠B = 90° - 28° = 62°
- ∵ ∠D与∠B对同一条弧AC
- ∴ ∠D = ∠B = 62°（同弧所对圆周角相等）

**考点**：圆周角定理、直角三角形

## 二、填空题

### 题目4：因式分解
**题目**：分解因式：x² - 4x + 4 = _______

**答案**：(x - 2)²

**解析**：
- 观察：a² - 2ab + b² = (a - b)²
- x² - 4x + 4 = x² - 2·x·2 + 2²
- = (x - 2)²

**考点**：完全平方公式

### 题目5：概率统计
**题目**：一个不透明的袋子中装有3个红球和2个白球，这些球除颜色外完全相同。从中随机摸出一个球是红球的概率是_______

**答案**：3/5

**解析**：
- 总球数 = 3 + 2 = 5
- 红球数 = 3
- P(红球) = 3/5

**考点**：概率计算

---

### 题目6：方程应用
**题目**：某商品原价200元，连续两次降价x%后售价为128元，则x = _______

**答案**：20

**解析**：
- 第一次降价后：200(1 - x%)
- 第二次降价后：200(1 - x%)²
- 列方程：200(1 - x%)² = 128
- (1 - x%)² = 0.64
- 1 - x% = 0.8（负值舍去）
- x% = 0.2
- x = 20

**考点**：一元二次方程应用、增长率问题

## 三、解答题

### 题目7：一元二次方程
**题目**：解方程：x² - 5x + 6 = 0

**解答**：
方法一：因式分解法
- x² - 5x + 6 = 0
- (x - 2)(x - 3) = 0
- x - 2 = 0 或 x - 3 = 0
- x₁ = 2，x₂ = 3

方法二：公式法
- a = 1，b = -5，c = 6
- Δ = b² - 4ac = 25 - 24 = 1 > 0
- x = [5 ± √1] / 2
- x₁ = 3，x₂ = 2

**考点**：一元二次方程的解法

### 题目8：函数综合
**题目**：已知一次函数y = kx + b的图像经过点A(1, 3)和B(-2, -3)。
(1) 求这个一次函数的解析式；
(2) 判断点C(2, 5)是否在该函数图像上。

**解答**：
(1) 将A(1, 3)和B(-2, -3)代入y = kx + b
- 3 = k + b  ①
- -3 = -2k + b  ②
- ①-②：6 = 3k，k = 2
- 代入①：b = 1
- ∴ y = 2x + 1

(2) 将x = 2代入y = 2x + 1
- y = 2×2 + 1 = 5
- ∵ 点C坐标为(2, 5)
- ∴ 点C在该函数图像上

**考点**：待定系数法、函数图像

### 题目9：几何证明与计算
**题目**：如图，在△ABC中，AB = AC，D是BC的中点，DE⊥AB于E，DF⊥AC于F。
求证：DE = DF

**证明**：
连接AD

∵ AB = AC，D是BC中点
∴ AD⊥BC（等腰三角形三线合一）
∴ ∠ADB = ∠ADC = 90°

在Rt△ABD和Rt△ACD中
- AB = AC（已知）
- AD = AD（公共边）
- ∠ADB = ∠ADC = 90°
∴ Rt△ABD ≌ Rt△ACD（HL）
∴ ∠BAD = ∠CAD

∵ DE⊥AB，DF⊥AC
∴ ∠AED = ∠AFD = 90°

在Rt△AED和Rt△AFD中
- ∠AED = ∠AFD = 90°
- ∠EAD = ∠FAD
- AD = AD（公共边）
∴ Rt△AED ≌ Rt△AFD（AAS）
∴ DE = DF

**考点**：等腰三角形性质、全等三角形

## 四、压轴题

### 题目10：二次函数综合
**题目**：已知抛物线y = ax² + bx + c经过点A(-1, 0)、B(3, 0)、C(0, -3)。
(1) 求抛物线的解析式；
(2) 求抛物线的顶点坐标；
(3) 若点P在抛物线上，且△PAB的面积为6，求点P的坐标。

**解答**：
(1) 设抛物线为y = a(x + 1)(x - 3)
- 将C(0, -3)代入：-3 = a(0 + 1)(0 - 3)
- -3 = -3a
- a = 1
- ∴ y = (x + 1)(x - 3) = x² - 2x - 3

(2) y = x² - 2x - 3 = (x - 1)² - 4
- 顶点坐标为(1, -4)

(3) AB = 3 - (-1) = 4
- 设P点纵坐标为y₀
- S△PAB = (1/2) × 4 × |y₀| = 6
- |y₀| = 3
- y₀ = 3 或 y₀ = -3

当y₀ = 3时：x² - 2x - 3 = 3
- x² - 2x - 6 = 0
- x = 1 ± √7

当y₀ = -3时：x = 0（即点C）

∴ P点坐标为(1+√7, 3)或(1-√7, 3)或(0, -3)

**考点**：二次函数解析式、顶点坐标、面积计算
