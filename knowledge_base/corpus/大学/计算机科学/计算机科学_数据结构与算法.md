# 计算机科学基础知识点

## 第一部分 数据结构

### 1.1 线性表

**顺序表（数组）**：
- 特点：连续存储，随机访问
- 时间复杂度：
  - 查找：O(1)
  - 插入/删除：O(n)
- 优点：支持随机访问
- 缺点：插入删除效率低，空间固定

**链表**：
- 单链表：每个节点指向下一个
- 双链表：每个节点指向前后两个
- 循环链表：尾节点指向头节点
- 时间复杂度：
  - 查找：O(n)
  - 插入/删除：O(1)（已知位置）
- 优点：动态分配，插入删除方便
- 缺点：不支持随机访问

### 1.2 栈和队列

**栈（Stack）**：
- 特点：后进先出（LIFO）
- 操作：push（入栈）、pop（出栈）、peek（查看栈顶）
- 应用：
  - 函数调用栈
  - 表达式求值
  - 括号匹配
  - 深度优先搜索（DFS）

**队列（Queue）**：
- 特点：先进先出（FIFO）
- 操作：enqueue（入队）、dequeue（出队）
- 类型：
  - 普通队列
  - 循环队列
  - 双端队列（Deque）
  - 优先队列（堆实现）
- 应用：
  - 广度优先搜索（BFS）
  - 任务调度
  - 缓冲区

### 1.3 树

**二叉树**：
- 定义：每个节点最多两个子节点
- 性质：
  - 第i层最多2^(i-1)个节点
  - 深度为k的二叉树最多2^k - 1个节点
  - n₀ = n₂ + 1（叶子节点数 = 度为2的节点数 + 1）

**二叉搜索树（BST）**：
- 性质：左子树 < 根 < 右子树
- 操作：查找、插入、删除 O(log n) ~ O(n)

**平衡二叉树（AVL）**：
- 性质：任意节点左右子树高度差 ≤ 1
- 操作：查找、插入、删除 O(log n)
- 旋转：LL、RR、LR、RL

**红黑树**：
- 性质：
  - 节点是红色或黑色
  - 根节点是黑色
  - 叶子节点（NIL）是黑色
  - 红色节点的子节点必须是黑色
  - 从根到叶子的所有路径包含相同数目的黑色节点
- 应用：TreeMap、TreeSet

**B树/B+树**：
- 特点：多路平衡查找树
- 应用：数据库索引、文件系统

**树的遍历**：
- 前序：根 → 左 → 右
- 中序：左 → 根 → 右
- 后序：左 → 右 → 根
- 层序：逐层遍历（BFS）

### 1.4 图

**图的表示**：
- 邻接矩阵：适合稠密图
- 邻接表：适合稀疏图

**图的遍历**：
- 深度优先搜索（DFS）：栈/递归
- 广度优先搜索（BFS）：队列

**最短路径**：
- Dijkstra算法：单源最短路径（非负权）
- Bellman-Ford算法：单源最短路径（可有负权）
- Floyd算法：多源最短路径

**最小生成树**：
- Prim算法：从顶点出发
- Kruskal算法：从边出发

**拓扑排序**：
- 应用：有向无环图（DAG）
- 方法：入度为0的顶点优先

### 1.5 哈希表

**哈希函数**：
- 除留余数法：h(key) = key % m
- 乘法哈希法
- 全域哈希

**冲突解决**：
- 链地址法（拉链法）
- 开放地址法：线性探测、二次探测、双重哈希

**时间复杂度**：
- 平均：O(1)
- 最坏：O(n)

### 1.6 堆

**性质**：
- 完全二叉树
- 大顶堆：父节点 ≥ 子节点
- 小顶堆：父节点 ≤ 子节点

**操作**：
- 插入：O(log n)
- 删除最大/最小：O(log n)
- 建堆：O(n)

**应用**：
- 优先队列
- 堆排序
- Top K问题

## 第二部分 算法

### 2.1 排序算法

**冒泡排序**：
- 时间：O(n²)
- 空间：O(1)
- 稳定

**选择排序**：
- 时间：O(n²)
- 空间：O(1)
- 不稳定

**插入排序**：
- 时间：O(n²)
- 空间：O(1)
- 稳定

**快速排序**：
- 时间：平均O(n log n)，最坏O(n²)
- 空间：O(log n)
- 不稳定
- 思想：分治

**归并排序**：
- 时间：O(n log n)
- 空间：O(n)
- 稳定
- 思想：分治

**堆排序**：
- 时间：O(n log n)
- 空间：O(1)
- 不稳定

**计数排序**：
- 时间：O(n+k)
- 空间：O(k)
- 稳定
- 适用：整数，范围小

**基数排序**：
- 时间：O(d(n+k))
- 空间：O(n+k)
- 稳定

### 2.2 查找算法

**顺序查找**：O(n)

**二分查找**：
- 时间：O(log n)
- 条件：有序数组

**哈希查找**：O(1)

### 2.3 动态规划

**特征**：
- 最优子结构
- 重叠子问题

**步骤**：
1. 定义状态
2. 状态转移方程
3. 初始化
4. 计算顺序

**经典问题**：
- 斐波那契数列
- 背包问题
- 最长公共子序列（LCS）
- 最长递增子序列（LIS）
- 编辑距离

### 2.4 贪心算法

**特征**：
- 局部最优 → 全局最优
- 无后效性

**经典问题**：
- 活动选择
- 哈夫曼编码
- 最小生成树

### 2.5 回溯算法

**思想**：
- 深度优先搜索
- 剪枝优化

**经典问题**：
- N皇后
- 全排列
- 子集
- 组合总和

### 2.6 分治算法

**思想**：
- 分解：分成子问题
- 解决：递归求解
- 合并：合并子问题解

**经典问题**：
- 归并排序
- 快速排序
- 二分查找

## 第三部分 算法复杂度

### 3.1 时间复杂度

**常见复杂度**：
- O(1)：常数
- O(log n)：对数
- O(n)：线性
- O(n log n)：线性对数
- O(n²)：平方
- O(n³)：立方
- O(2ⁿ)：指数
- O(n!)：阶乘

**主定理**：
T(n) = aT(n/b) + f(n)

### 3.2 空间复杂度

**定义**：算法执行过程中所需的额外空间

**分类**：
- 输入空间
- 辅助空间
- 输出空间

## 易错点提醒

1. **数组与链表**：根据场景选择合适的数据结构
2. **递归**：注意终止条件，避免栈溢出
3. **排序稳定性**：相同元素相对位置是否改变
4. **动态规划**：状态定义和转移方程是关键
5. **时间复杂度**：注意最好、平均、最坏情况
