# 大学物理核心知识点

## 第一章 质点运动学

### 1.1 位置矢量与位移
- **位置矢量**：r = xi + yj + zk
- **位移**：Δr = r₂ - r₁
- **路程**：轨迹长度（标量）

### 1.2 速度与加速度
- **平均速度**：v̄ = Δr/Δt
- **瞬时速度**：v = dr/dt = ṙ
- **速率**：v = |v| = ds/dt
- **加速度**：a = dv/dt = v̇ = r̈

### 1.3 圆周运动
- **角速度**：ω = dθ/dt
- **角加速度**：α = dω/dt
- **线速度**：v = ωr
- **切向加速度**：aₜ = dv/dt = αr
- **法向加速度**：aₙ = v²/r = ω²r
- **总加速度**：a = √(aₜ² + aₙ²)

## 第二章 牛顿运动定律

### 2.1 牛顿三定律
- **第一定律**：惯性定律
- **第二定律**：F = ma = dp/dt
- **第三定律**：F₁₂ = -F₂₁

### 2.2 常见力
- **重力**：G = mg
- **弹性力**：F = -kx
- **摩擦力**：f = μN
- **万有引力**：F = Gm₁m₂/r²

### 2.3 非惯性系
- **惯性力**：F* = -ma₀
- **离心力**：F = mω²r

## 第三章 动量与角动量

### 3.1 动量定理
- **动量**：p = mv
- **冲量**：I = ∫F dt
- **动量定理**：I = Δp

### 3.2 动量守恒
- **条件**：系统所受合外力为零
- **表达式**：Σp = 常量

### 3.3 角动量
- **角动量**：L = r × p
- **力矩**：M = r × F
- **角动量定理**：M = dL/dt
- **角动量守恒**：M = 0时，L = 常量

## 第四章 功和能

### 4.1 功
- **定义**：W = ∫F·dr
- **功率**：P = dW/dt = F·v

### 4.2 动能定理
- **动能**：Eₖ = (1/2)mv²
- **动能定理**：W = ΔEₖ

### 4.3 势能
- **重力势能**：Eₚ = mgh
- **弹性势能**：Eₚ = (1/2)kx²
- **引力势能**：Eₚ = -Gm₁m₂/r

### 4.4 机械能守恒
- **条件**：只有保守力做功
- **表达式**：E = Eₖ + Eₚ = 常量

## 第五章 刚体转动

### 5.1 转动惯量
- **定义**：J = Σmᵢrᵢ² = ∫r²dm
- **平行轴定理**：J = Jc + md²

**常见刚体转动惯量**：
- 细棒（轴过中心）：J = (1/12)ml²
- 圆盘（轴过中心）：J = (1/2)mr²
- 球体：J = (2/5)mr²

### 5.2 转动定律
- **转动定律**：M = Jα
- **角动量**：L = Jω
- **转动动能**：Eₖ = (1/2)Jω²

## 第六章 静电场

### 6.1 库仑定律
- **公式**：F = kq₁q₂/r² = q₁q₂/(4πε₀r²)
- **k = 9.0×10⁹ N·m²/C²**

### 6.2 电场强度
- **定义**：E = F/q₀
- **点电荷**：E = kQ/r²
- **叠加原理**：E = ΣEᵢ

### 6.3 高斯定理
- **公式**：∮E·dS = Q/ε₀
- **应用**：球对称、柱对称、面对称

### 6.4 电势
- **定义**：U = W/q₀ = ∫E·dl
- **点电荷**：U = kQ/r
- **电势差**：U₁₂ = U₁ - U₂

### 6.5 电容
- **定义**：C = Q/U
- **平行板电容器**：C = ε₀S/d
- **电容器能量**：W = (1/2)QU = (1/2)CU²

## 第七章 恒定磁场

### 7.1 磁感应强度
- **定义**：F = qv × B
- **单位**：特斯拉（T）

### 7.2 毕奥-萨伐尔定律
- **公式**：dB = (μ₀/4π) × (Idl × r)/r³
- **直导线**：B = (μ₀I)/(2πr)
- **圆电流中心**：B = μ₀I/(2R)

### 7.3 安培定律
- **公式**：∮B·dl = μ₀ΣI
- **应用**：无限长直导线、螺线管

### 7.4 洛伦兹力
- **公式**：F = qv × B
- **圆周运动**：r = mv/(qB)，T = 2πm/(qB)

### 7.5 安培力
- **公式**：F = I∫dl × B
- **直导线**：F = BIL sin θ

## 第八章 电磁感应

### 8.1 法拉第电磁感应定律
- **公式**：ε = -dΦ/dt
- **磁通量**：Φ = ∫B·dS

### 8.2 动生电动势
- **公式**：ε = ∫(v × B)·dl
- **直导线**：ε = BLv

### 8.3 感生电动势
- **涡旋电场**：∮E·dl = -dΦ/dt

### 8.4 自感与互感
- **自感**：ε = -L(dI/dt)
- **自感系数**：L = Φ/I
- **自感能量**：W = (1/2)LI²

## 易错点提醒

1. **矢量运算**：注意方向，使用右手定则
2. **参考系**：明确惯性系与非惯性系
3. **守恒定律**：验证守恒条件
4. **电场磁场**：区分电场力和磁场力
5. **单位制**：统一使用国际单位制
