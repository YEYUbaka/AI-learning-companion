# 高等数学核心知识点

## 第一章 函数与极限

### 1.1 函数
- **定义域与值域**：自然定义域
- **函数性质**：
  - 单调性：增函数、减函数
  - 奇偶性：f(-x) = -f(x)奇函数，f(-x) = f(x)偶函数
  - 周期性：f(x+T) = f(x)
  - 有界性：|f(x)| ≤ M

### 1.2 极限
- **数列极限**：lim(n→∞) aₙ = A
- **函数极限**：
  - x→x₀时：lim(x→x₀) f(x) = A
  - x→∞时：lim(x→∞) f(x) = A

**极限运算法则**：
- 和差：lim[f(x)±g(x)] = lim f(x) ± lim g(x)
- 积：lim[f(x)·g(x)] = lim f(x) · lim g(x)
- 商：lim[f(x)/g(x)] = lim f(x) / lim g(x)（分母不为0）

**重要极限**：
- lim(x→0) (sin x)/x = 1
- lim(x→∞) (1 + 1/x)ˣ = e
- lim(x→0) (1 + x)^(1/x) = e

### 1.3 无穷小与无穷大
- **无穷小**：极限为0的变量
- **无穷大**：绝对值无限增大的变量
- **关系**：无穷大的倒数是无穷小

**无穷小的比较**：
- 高阶无穷小：lim β/α = 0
- 低阶无穷小：lim β/α = ∞
- 同阶无穷小：lim β/α = c ≠ 0
- 等价无穷小：lim β/α = 1

**常用等价无穷小**（x→0）：
- sin x ~ x
- tan x ~ x
- arcsin x ~ x
- arctan x ~ x
- ln(1+x) ~ x
- eˣ - 1 ~ x
- 1 - cos x ~ x²/2

### 1.4 连续性
- **定义**：lim(x→x₀) f(x) = f(x₀)
- **间断点**：
  - 第一类：左右极限存在（可去、跳跃）
  - 第二类：至少一侧极限不存在

**闭区间连续函数性质**：
- 有界性定理
- 最值定理
- 介值定理
- 零点定理

## 第二章 导数与微分

### 2.1 导数
- **定义**：f'(x₀) = lim(Δx→0) [f(x₀+Δx) - f(x₀)]/Δx
- **几何意义**：切线斜率
- **物理意义**：瞬时变化率

**基本求导公式**：
- (C)' = 0
- (xⁿ)' = nxⁿ⁻¹
- (sin x)' = cos x
- (cos x)' = -sin x
- (eˣ)' = eˣ
- (aˣ)' = aˣ ln a
- (ln x)' = 1/x
- (logₐx)' = 1/(x ln a)

**求导法则**：
- (u±v)' = u'±v'
- (uv)' = u'v + uv'
- (u/v)' = (u'v - uv')/v²
- 复合函数：[f(g(x))]' = f'(g(x))·g'(x)

### 2.2 微分
- **定义**：dy = f'(x)dx
- **几何意义**：切线纵坐标增量
- **近似计算**：f(x₀+Δx) ≈ f(x₀) + f'(x₀)Δx

### 2.3 微分中值定理

**罗尔定理**：
- 条件：[a,b]连续，(a,b)可导，f(a)=f(b)
- 结论：存在ξ∈(a,b)，使f'(ξ)=0

**拉格朗日中值定理**：
- 条件：[a,b]连续，(a,b)可导
- 结论：存在ξ∈(a,b)，使f(b)-f(a)=f'(ξ)(b-a)

**柯西中值定理**：
- 条件：f、g在[a,b]连续，(a,b)可导，g'(x)≠0
- 结论：存在ξ∈(a,b)，使[f(b)-f(a)]/[g(b)-g(a)]=f'(ξ)/g'(ξ)

### 2.4 洛必达法则
- **适用类型**：0/0型、∞/∞型
- **公式**：lim f(x)/g(x) = lim f'(x)/g'(x)
- **注意**：验证条件，可能需要多次使用

### 2.5 泰勒公式
- **麦克劳林公式**（x₀=0）：
  - eˣ = 1 + x + x²/2! + x³/3! + ...
  - sin x = x - x³/3! + x⁵/5! - ...
  - cos x = 1 - x²/2! + x⁴/4! - ...
  - ln(1+x) = x - x²/2 + x³/3 - ...
  - (1+x)ᵅ = 1 + αx + α(α-1)x²/2! + ...

### 2.6 函数的单调性与极值

**单调性判定**：
- f'(x) > 0：单调递增
- f'(x) < 0：单调递减

**极值判定**：
- 第一充分条件：f'(x₀)=0，左右两侧导数异号
- 第二充分条件：f'(x₀)=0，f''(x₀)≠0

**凹凸性与拐点**：
- f''(x) > 0：凹函数
- f''(x) < 0：凸函数
- 拐点：凹凸性改变的点

## 第三章 不定积分

### 3.1 原函数与不定积分
- **定义**：F'(x) = f(x)，则F(x)是f(x)的原函数
- **不定积分**：∫f(x)dx = F(x) + C

**基本积分公式**：
- ∫xⁿdx = xⁿ⁺¹/(n+1) + C（n≠-1）
- ∫1/x dx = ln|x| + C
- ∫eˣdx = eˣ + C
- ∫aˣdx = aˣ/ln a + C
- ∫sin x dx = -cos x + C
- ∫cos x dx = sin x + C
- ∫1/(1+x²) dx = arctan x + C
- ∫1/√(1-x²) dx = arcsin x + C

### 3.2 换元积分法

**第一类换元法**（凑微分）：
- ∫f[φ(x)]φ'(x)dx = ∫f(u)du

**第二类换元法**：
- 根式代换：√(a²-x²)令x=a sin t
- 三角代换：√(x²+a²)令x=a tan t

### 3.3 分部积分法
- **公式**：∫udv = uv - ∫vdu
- **口诀**：反对幂指三（选u的优先级）

## 第四章 定积分

### 4.1 定积分定义
- **定义**：∫ₐᵇf(x)dx = lim(λ→0)Σf(ξᵢ)Δxᵢ
- **几何意义**：曲边梯形面积

### 4.2 定积分性质
- 线性性：∫[αf+βg]dx = α∫fdx + β∫gdx
- 区间可加性：∫ₐᵇf = ∫ₐᶜf + ∫ᶜᵇf
- 比较定理：f≤g则∫f≤∫g

### 4.3 微积分基本定理
- **牛顿-莱布尼茨公式**：∫ₐᵇf(x)dx = F(b) - F(a)

### 4.4 定积分应用
- **平面图形面积**：A = ∫ₐᵇ|f(x)-g(x)|dx
- **旋转体体积**：V = π∫ₐᵇf²(x)dx
- **弧长**：s = ∫ₐᵇ√[1+(y')²]dx

## 易错点提醒

1. **极限运算**：注意运算法则的使用条件
2. **等价无穷小**：只能在乘除中替换，不能在加减中替换
3. **洛必达法则**：使用前验证0/0或∞/∞型
4. **不定积分**：别忘记加常数C
5. **定积分**：注意积分上下限
