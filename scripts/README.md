# 脚本目录说明

## 目录结构

- **setup/**: 环境安装和配置脚本
  - 检查系统环境（Python、Node.js、ODBC 等）
  - 安装依赖
  - 创建数据库
  - 虚拟环境配置

- **start/**: 服务启动脚本
  - 启动后端服务
  - 启动前端服务
  - 一键启动前后端

- **deploy/**: 部署相关脚本
  - 服务器部署
  - 环境修复

- **maintenance/**: 维护和修复脚本
  - 依赖修复
  - 数据库诊断

## 使用建议

1. 首次部署：先运行 `setup/` 中的环境检查和安装脚本
2. 日常开发：使用 `start/` 中的启动脚本
3. 生产部署：参考 `deploy/` 中的部署脚本
4. 遇到问题：查看 `maintenance/` 中的修复脚本
