# 🚀 快速打包指南

## 方法一：使用打包脚本（推荐）

### Windows PowerShell
```powershell
cd scripts
.\package_project.ps1
```

### Windows CMD
```cmd
cd scripts
package_project.bat
```

### Linux/Mac
```bash
cd scripts
chmod +x package_project.sh
./package_project.sh
```

打包完成后，文件会生成在 `packages/` 目录下。

## 方法二：手动打包

### 1. 创建打包目录
```bash
mkdir packages
```

### 2. 使用压缩工具打包

#### Windows
- 右键项目根目录 → 发送到 → 压缩(zipped)文件夹
- 或使用 7-Zip/WinRAR

#### Linux/Mac
```bash
zip -r packages/智学伴项目-$(date +%Y%m%d).zip . \
  -x "node_modules/*" \
  -x "__pycache__/*" \
  -x "*.pyc" \
  -x "venv/*" \
  -x ".venv/*" \
  -x "*.db" \
  -x "*.sqlite" \
  -x ".env" \
  -x "dist/*" \
  -x "build/*" \
  -x ".pytest_cache/*" \
  -x ".vscode/*" \
  -x ".idea/*"
```

## 📋 打包前检查清单

在打包前，请确认：

- [ ] 已更新 `README.md` 中的最新信息
- [ ] `backend/.env.template` 文件存在且完整
- [ ] `frontend/.env.development` 文件存在
- [ ] 所有源代码已保存
- [ ] 没有包含 `.env` 实际环境变量文件
- [ ] 没有包含 `node_modules/` 目录
- [ ] 没有包含数据库文件

## 📦 打包后验证

解压打包文件，确认：

- [ ] 可以正常解压
- [ ] 包含所有源代码目录
- [ ] 包含 `requirements.txt` 和 `package.json`
- [ ] 包含环境变量模板文件
- [ ] 不包含敏感信息（.env 文件）

## 🎯 分发建议

1. **文件大小**：如果超过 100MB，考虑使用：
   - 云盘分享（百度网盘、OneDrive、Google Drive）
   - Git LFS（如果使用 Git 仓库）
   - 分卷压缩

2. **传输方式**：
   - 小文件：直接发送
   - 大文件：使用云盘链接
   - 团队协作：使用 Git 仓库

3. **安全提醒**：
   - ⚠️ **绝对不要**包含 `.env` 文件
   - ⚠️ **绝对不要**包含真实的 API 密钥
   - ⚠️ **绝对不要**包含数据库文件（可能包含用户数据）
