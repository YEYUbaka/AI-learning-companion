# 智学伴前端设计指南

> 给前端设计同学的项目说明文档

## 一、项目概述

**智学伴** 是一个 AI 驱动的个性化学习平台，面向学生和教育工作者。核心功能包括：
- 智能学习计划生成
- AI 智能助手（Agent）
- 智能组卷系统
- 知识图谱可视化
- 学习数据分析
- RAG 知识库检索

**目标用户**：中学生、大学生、自学者、教师

## 四、设计规范（重要）

### 4.1 禁止使用的元素

#### ❌ Emoji 表情符号
- 代码中禁止使用任何 emoji（✅ ❌ 🚀 📝 等）
- 使用阿里巴巴矢量图标库（https://www.iconfont.cn/）的 SVG 图标
- 或使用文字标记：`[OK]`、`[FAIL]`、`[INFO]`、`[WARNING]`

#### ❌ AI 风格配色
- **禁止**：渐变蓝紫色（blue-purple gradient）
- **禁止**：磨砂效果（backdrop-blur、glassmorphism）
- **禁止**：霓虹发光效果（neon glow）
- **禁止**：过度阴影和透明模糊

### 4.2 推荐的设计风格

#### 配色方案（60-30-10 规则）
```css
/* 主色调（60%） */
--primary-blue: #2563eb;      /* 专业蓝 */
--dark-gray: #1e293b;         /* 深灰 */

/* 辅助色（30%） */
--success-green: #10b981;     /* 成功 */
--error-red: #ef4444;         /* 错误 */
--warning-orange: #f59e0b;    /* 警告 */

/* 背景色 */
/* 亮色模式 */
--bg-light: #ffffff;
--bg-light-secondary: #f9fafb;

/* 暗色模式 */
--bg-dark: #0f172a;           /* slate-900 */
--bg-dark-secondary: #1e293b; /* slate-800 */
```

#### 设计原则
1. **简洁、专业、高效** - 避免过度装饰
2. **可读性优先** - 确保文字清晰易读
3. **一致性** - 统一的间距、圆角、阴影
4. **响应式** - 适配桌面、平板、手机

#### 参考项目
- **GitHub / GitLab** - 代码托管平台的简洁风格
- **Notion / Linear** - 生产力工具的专业感
- **Stripe / Vercel** - 开发者平台的现代设计

## 五、核心功能说明

### 5.1 AI 助手（Agent）
**位置**：`/agent`（导航栏"AI助手"）

**功能特点**：
- 支持三种模式：ReAct、Chain of Thought、Function Calling
- 内置工具：网络搜索、生成学习计划、构建知识图谱、知识库检索
- 实时展示 AI 思考过程和工具调用步骤
- 支持 Markdown 渲染（含 LaTeX 公式）

**设计要点**：
- 对话气泡需区分用户/AI/系统消息
- 工具调用步骤需可折叠展开
- 思考过程用不同颜色标识（思考/行动/观察）
- 支持代码高亮显示

### 5.2 知识图谱
**位置**：`/learning-map`

**功能特点**：
- 使用 `react-force-graph-2d` 渲染力导向图
- 节点表示知识点，边表示关系
- 支持拖拽、缩放、点击节点查看详情

**设计要点**：
- 节点颜色区分不同类型（章节/概念/公式）
- 悬停显示知识点名称
- 侧边栏展示节点详细信息

### 5.3 智能组卷
**位置**：`/quiz`

**功能特点**：
- 配置难度、题型、数量
- AI 生成试卷（选择题、填空题、解答题）
- 支持 LaTeX 公式渲染
- 导出 PDF/Word 格式

**设计要点**：
- 表单设计清晰，参数配置直观
- 试卷预览支持打印样式
- 答案解析可折叠显示

### 5.4 学习数据分析
**位置**：`/dashboard`

**功能特点**：
- 使用 Recharts 展示学习统计
- 图表类型：折线图、柱状图、饼图
- 数据维度：学习时长、测验成绩、知识点掌握度

**设计要点**：
- 图表配色与主题一致
- 数据卡片布局合理
- 支持时间范围筛选

## 六、状态管理

### 6.1 Zustand Store
**位置**：`frontend/src/store/`

#### 主要 Store
- `authStore.js` - 用户认证状态（token、userInfo）
- `themeStore.js` - 主题切换（亮色/暗色）
- `agentStore.js` - Agent 对话历史

#### 使用示例
```javascript
import { useAuthStore } from '../store/authStore';

function MyComponent() {
  const { userInfo, logout } = useAuthStore();

  return (
    <div>
      <p>欢迎，{userInfo?.username}</p>
      <button onClick={logout}>退出登录</button>
    </div>
  );
}
```

### 6.2 安全规则（重要）
- **Token 存储**：严格使用 `sessionStorage`，禁止 `localStorage`
- **Admin 判断**：仅通过 `userInfo.role === 'admin'` 判断，禁止 email 前缀检查

## 九、设计建议

### 9.1 布局建议
1. **导航栏**：固定顶部，包含 Logo、菜单、用户头像、主题切换
2. **侧边栏**：管理后台使用侧边栏导航
3. **主内容区**：最大宽度 1280px，居中显示
4. **响应式断点**：
   - 移动端：< 640px
   - 平板：640px - 1024px
   - 桌面：> 1024px

### 9.2 组件设计
1. **按钮**：
   - 主按钮：蓝色背景，白色文字
   - 次要按钮：白色背景，蓝色边框
   - 危险按钮：红色背景
   - 禁用状态：灰色，降低透明度

2. **表单**：
   - 输入框：圆角 6px，边框 1px
   - 标签：字体 14px，灰色
   - 错误提示：红色文字，输入框红色边框

3. **卡片**：
   - 白色背景（亮色模式）/ 深灰背景（暗色模式）
   - 圆角 8px
   - 阴影：`shadow-sm`（轻微）

4. **对话气泡**：
   - 用户消息：右对齐，蓝色背景
   - AI 消息：左对齐，灰色背景
   - 系统消息：居中，黄色背景

### 9.3 动画建议
- 页面切换：淡入淡出（200ms）
- 按钮悬停：轻微放大（scale 1.05）
- 加载状态：旋转动画或骨架屏
- 避免过度动画，保持流畅

### 9.4 图标建议
- 使用阿里巴巴矢量图标库（https://www.iconfont.cn/）
- 或使用 Heroicons（https://heroicons.com/）
- 图标大小：16px（小）、20px（中）、24px（大）
- 颜色与文字保持一致

## 十、注意事项

### 10.1 性能优化
- 使用 `React.memo` 避免不必要的重渲染
- 大列表使用虚拟滚动（react-window）
- 图片懒加载
- 代码分割（React.lazy + Suspense）

### 10.2 可访问性
- 按钮和链接使用语义化标签
- 表单输入框关联 label
- 图片添加 alt 属性
- 键盘导航支持（Tab 键）

### 10.3 浏览器兼容性
- 目标浏览器：Chrome、Firefox、Safari、Edge（最新两个版本）
- 不支持 IE11

### 10.4 暗色模式
- 使用 TailwindCSS 的 `dark:` 前缀
- 主题切换通过 `themeStore` 管理
- 确保所有颜色在暗色模式下可读
