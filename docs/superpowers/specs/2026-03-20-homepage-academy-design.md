# 首页学院风改版设计

- 日期：2026-03-20
- 范围：`frontend/src/components/Navbar.jsx`、`frontend/src/pages/Dashboard.jsx`、`frontend/src/styles/global.css`
- 状态：已确认设计方向，待进入实现计划

## 1. 背景

当前前台首页基于 `Navbar + Dashboard` 组合工作，信息结构基本可用，但视觉气质仍偏通用 SaaS/AI 面板：

- 首页入口层级清楚，但品牌辨识度不够。
- 色彩仍然偏默认产品色，缺少“教育品牌”“学院氛围”的稳定感。
- 图标主要依赖内联 SVG，风格不统一，后续扩展成本高。
- 深色模式与浅色模式的品牌一致性不足，容易变成“两套不同产品”。

本次改版只处理首页相关范围，不扩展到前台全站。目标是先把首页品牌气质立住，再逐步向其他页面扩散。

## 2. 目标与非目标

### 2.1 目标

- 将首页视觉从“AI 工具面板”调整为“高质量教育品牌首页”。
- 建立完整的浅色 / 深色学院风配色系统。
- 在首页中明显使用阿里 `iconfont.cn` 图标，但仍保持克制，不做炫技风。
- 保留现有首页信息架构与主要功能，不做大范围交互重构。
- 为后续全站风格统一建立可复用的颜色与图标约束。

### 2.2 非目标

- 本轮不改动登录、注册、学习计划、知识图谱等其他页面。
- 本轮不改动后端接口和 Dashboard 数据结构。
- 本轮不重新设计整体路由结构。
- 本轮不追求完整品牌系统文档，只定义首页所需设计 token 和规则。

## 3. 设计方向

采用已确认的 `A. 书院式首页` 方向。

核心判断：

- 首页不是营销落地页，也不是运营大屏。
- 首页要像“书院门厅”或“现代教育机构前厅”：稳、克制、有内容密度。
- 色彩以米白承载内容、墨绿建立品牌主体、深棕承担强调与温度。
- 图标存在感要比当前明显，但不应成为主视觉中心。

## 4. 视觉系统

### 4.1 浅色模式

推荐主色板：

- 页面底色：`#F4EBDD`
- 卡片底色：`#FBF6EE`
- 次级浅底：`#F1E6D5`
- 主品牌墨绿：`#1F4536`
- 深层墨绿：`#163429`
- 深棕强调：`#7A5638`
- 铜棕高亮：`#B48763`
- 主文字：`#2D241D`
- 次文字：`#675B4F`
- 分隔边框：`rgba(45, 36, 29, 0.10)`

视觉规则：

- 页面不用大面积科技蓝或紫色渐变。
- 主欢迎区使用深墨绿为背景，形成首页记忆点。
- 内容区维持米白与纸白层次，不做玻璃拟态。
- 强调色优先使用铜棕，不使用高饱和亮蓝。

### 4.2 深色模式

推荐深色系：

- 页面底色：`#13231D`
- 容器底色：`#1B2F27`
- 卡片底色：`#22382E`
- 次级底色：`#294439`
- 主文字：`#E9DDC8`
- 次文字：`#C3B39A`
- 边框：`rgba(233, 221, 200, 0.12)`
- 铜棕强调：`#B48763`
- 亮米色按钮文字：`#F8F1E7`

视觉规则：

- 深色模式仍维持学院风，不退回通用炭黑后台。
- 深墨绿替代纯黑作为页面基底。
- 强调色延续铜棕与暖米色，保持与浅色模式同一品牌家族。

### 4.3 字体气质

- 品牌标题和欢迎区主标题可使用 serif 风格字体栈营造书卷感。
- 正文、按钮、图表标签继续使用高可读 sans-serif。
- 标题和正文要有明显层级差，不依赖颜色堆砌。

建议：

- 标题：`Georgia`, `"Times New Roman"`, `"Noto Serif SC"`, serif
- 正文：`"Segoe UI"`, `"PingFang SC"`, `"Microsoft YaHei"`, sans-serif

## 5. 首页信息结构

Dashboard 继续保留三层结构，但更换视觉表达。

### 5.1 第一层：欢迎区

保留欢迎语与主操作，但样式改为“书院门厅”：

- 深墨绿大标题区，承接首页第一视觉。
- 显示欢迎语、学习状态摘要、主操作按钮。
- 主按钮使用暖米或铜棕反差，次按钮使用描边或弱填充。
- 欢迎区内可以加入 1 到 2 个高优先级状态点，不堆太多指标。

### 5.2 第二层：核心统计卡

保留现有 4 张卡片：

- 平均得分
- 完成率
- 已完成测评
- 学习计划

调整原则：

- 卡片颜色不再各自使用强饱和彩色底。
- 图标明显保留，但放到统一的图标容器中。
- 通过卡片底色层级、排版和 icon 容器建立统一感。
- 数字突出，说明文字压低存在感。

### 5.3 第三层：图表与工具入口

图表区域保留，但要去“默认数据后台”的味道：

- 图表线条与柱状色改成学院色系。
- Tooltip、网格线、轴标签同步品牌配色。
- 图表卡片圆角和边框语言与其他卡片统一。

工具入口区域调整为更像“学习入口目录”：

- 每个工具卡使用统一 icon 容器。
- 卡片 hover 不是高亮发光，而是边框、阴影、轻微位移。
- 文案保持简洁，不写满“AI”“智能化”等口号。

## 6. Navbar 改造

Navbar 是首页品牌建立的重要入口，需要与 Dashboard 使用同一套学院风。

### 6.1 结构不变

保留现有：

- Logo / 品牌区
- 主导航
- 主题切换
- 用户信息
- 退出按钮
- 移动端菜单

### 6.2 风格调整

- 顶栏背景从普通白色 / 深色栏改成学院风纸白 / 深墨绿。
- 品牌区增加“题签感”：
  - 品牌文字更稳重
  - 可搭配小型图标或徽记块
- 导航激活态不再使用偏蓝的默认高亮。
- 激活态采用墨绿或铜棕强调线 / 底 / 图标着色。
- 主题切换下拉与移动端菜单也统一到学院色板。

### 6.3 图标规则

本轮 Navbar 图标使用更明显：

- 桌面导航加入阿里图标
- 移动端导航加入阿里图标
- 主题切换保留图标，但颜色与容器样式统一

但要避免：

- 每个导航项都变成高彩色按钮
- 图标尺寸过大压过文字
- 过多填充图标导致视觉变重

## 7. 阿里 iconfont 接入策略

用户已确认采用 `iconfont.cn 项目` 方式。

### 7.1 接入原则

- 组件内部不再继续扩散大量手写内联 SVG。
- 用单一 iconfont 项目统一首页所需图标风格。
- 优先选择线性、圆角适中、笔画统一的图标。
- 首页图标先“明显”使用，后续根据效果再减量。

### 7.2 本轮使用区域

- Navbar 主导航
- 移动端菜单
- Dashboard 欢迎区辅助信息
- Dashboard 4 张统计卡
- Dashboard 工具入口卡
- 必要的小节标题或提示项

### 7.3 图标风格约束

- 优先线性图标，不优先填充图标
- 笔画统一，避免一个细一个粗
- 不使用科技感过强、赛博感强的图标
- 图标容器应统一圆角、边框和背景层级

### 7.4 实现方式建议

- 增加一个首页专用或通用图标封装层
- 封装图标名称到页面语义，而不是在页面里直接散落 className 或 unicode
- 如果 `iconfont.cn` 在线资源不稳定，保留本地映射和降级策略

## 8. 组件改造边界

### 8.1 `global.css`

负责：

- 全局颜色 token
- 浅色 / 深色主题变量
- 字体气质和基础背景
- 通用边框、卡片、阴影、按钮的基础语义变量

不负责：

- 首页具体布局
- 大量页面局部样式耦合

### 8.2 `Navbar.jsx`

负责：

- 题签式品牌头部
- 图标化导航
- 桌面 / 移动端一致的学院风交互状态

### 8.3 `Dashboard.jsx`

负责：

- 欢迎区重构
- 统计卡片风格统一
- 图表区配色与容器统一
- 工具入口卡片改造成“学习目录入口”

## 9. 交互与动效

动效原则：

- 只保留必要、克制的动态反馈
- 不做 AI 风格微光、漂浮、玻璃反射动画

允许的动效：

- 卡片 hover 轻微上移
- 阴影轻度增强
- 导航激活态平滑过渡
- 图标容器颜色轻微变化

避免的动效：

- 大面积渐变流动
- 霓虹发光
- 连续浮动元素
- 高频装饰粒子

## 10. 文案原则

- 首页语气从“AI 产品宣传”改成“学习平台引导”。
- 减少堆叠“智能”“AI”“自动化”类标签。
- 强调学习进展、学习工具、学习路径。
- 按钮文案尽量具体，例如：
  - `继续今日学习`
  - `查看学习报告`
  - `进入知识图谱`

## 11. 技术与实现约束

- 不改变现有 Dashboard 接口调用逻辑。
- 不新增依赖复杂的设计系统库。
- 保持移动端可用性。
- 保持现有主题切换逻辑，只替换视觉 token 和局部结构。
- 不因为图标改造而破坏页面渲染性能。

## 12. 验证标准

完成后至少满足以下标准：

- `Navbar + Dashboard` 在浅色模式下明显具备学院风，而非通用后台风。
- 深色模式保持同一品牌气质，不是独立的一套普通深色皮肤。
- 页面图标风格统一，且阿里图标使用明显但不过量。
- 现有首页信息结构与功能入口保持可用。
- 响应式布局在桌面和移动端都不塌陷。
- 前端构建通过。

## 13. 实现顺序建议

1. 在 `global.css` 中建立首页所需色彩 token 与字体基调
2. 改造 `Navbar.jsx` 的品牌区、导航视觉和移动端菜单
3. 改造 `Dashboard.jsx` 欢迎区与统计卡
4. 统一图表色、工具入口卡与图标容器
5. 接入 `iconfont.cn` 图标并替换首页相关图标
6. 验证浅色 / 深色模式与移动端展示

## 14. 风险与注意点

- 当前代码中存在部分中文编码异常，改造时要避免继续扩散乱码内容。
- 如果 `iconfont.cn` 接入方式不稳定，需准备本地回退方案。
- Dashboard 现有 JSX 较长，实现时应避免让文件继续无序膨胀，必要时拆出首页子组件。
- 深色模式若仅简单反色，会丢失学院感，需要单独设计深色 token。

## 15. 最终结论

本次首页改版采用：

- 方向：`书院式首页`
- 视觉：`米白 + 墨绿 + 深棕`
- 图标：`iconfont.cn 项目接入，首页明显使用`
- 范围：`Navbar + Dashboard`
- 主题：`浅色与深色模式都做完整学院风`

该设计确认后，下一步进入实现计划，不直接扩展到其他前台页面。
