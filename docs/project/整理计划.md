# 项目文件整理计划

## 整理目标
1. 清理根目录，只保留核心文件
2. 统一脚本管理
3. 统一文档管理
4. 归档临时和测试文件

## 新的目录结构

```
Web/
├── backend/              # 后端代码（保持不变）
├── frontend/             # 前端代码（保持不变）
├── scripts/              # 统一的脚本目录
│   ├── setup/           # 安装和环境配置脚本
│   ├── start/           # 启动脚本
│   ├── deploy/          # 部署脚本
│   └── maintenance/     # 维护脚本
├── docs/                 # 统一的文档目录
│   ├── deployment/      # 部署文档
│   ├── troubleshooting/ # 故障排查文档
│   ├── development/     # 开发文档
│   └── competition/     # 比赛相关文档
├── _archive/            # 归档目录（不常用的文件）
│   ├── old_scripts/     # 旧脚本备份
│   └── temp_files/      # 临时文件
├── .cursor/             # Cursor 配置
├── .venv/               # Python 虚拟环境
├── logs/                # 日志目录
├── README.md            # 项目说明
├── CLAUDE.md            # Claude Code 指南
├── LICENSE              # 许可证
├── .gitignore           # Git 忽略文件
└── docker-compose.yml   # Docker 配置
```

## 整理操作

### 1. 脚本文件整理
- 根目录的 .bat 文件 → scripts/对应子目录
- bash/ 文件夹内容 → _archive/old_scripts/
- 部署脚本/ 文件夹内容 → scripts/deploy/

### 2. 文档整理
- 根目录的 .md 文件 → docs/对应子目录
- backend/ 的文档文件 → docs/troubleshooting/
- documents/ 的内容 → docs/competition/

### 3. 临时文件清理
- backend/ 的测试 .py 文件 → _archive/temp_files/
- AI-learning-companion-main.zip → _archive/
- dummy 文件 → 删除

### 4. 保留在根目录的文件
- README.md
- CLAUDE.md
- LICENSE
- .gitignore
- docker-compose.yml
- 创建数据库.sql（常用）
