# 测试账号说明

## 使用原则

- 本文档不提供任何真实明文密码。
- 测试执行统一使用占位符，由环境维护人按当前环境实际值提供。
- 历史账号密码治理已改为“全量重置 + 自助改密 / 管理员代改”，不要再假设仓库中存在固定默认密码。

## 账号占位符

| 账号类型 | 占位符 | 说明 |
| --- | --- | --- |
| 管理员账号 | `ADMIN_EMAIL / ADMIN_PASSWORD` | 必须满足 `role=admin` |
| 普通用户账号 | `USER_EMAIL / USER_PASSWORD` | 用于普通学习主流程 |
| 全量重置后的默认密码 | `BULK_RESET_DEFAULT_PASSWORD` | 仅在执行全量重置脚本时通过 CLI 或 `.env` 提供，不写入仓库 |

## 使用建议

- 需要管理员账号时，优先由环境维护人提供现成账号。
- 需要批量重置全库密码时，使用 `backend/scripts/reset_all_user_passwords.py`。
- 用户登录后可通过前端 `/change-password` 自助改密。
- 管理员可在后台用户管理页对指定用户执行显式改密。

## 禁止事项

- 不要在文档、脚本、提交记录中写入真实密码。
- 不要依赖旧版“账号类型 + 123”之类的固定密码约定。
- 不要把全量重置默认密码提交到 Git。
