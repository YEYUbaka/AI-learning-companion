# 智学伴手动测试用例

## 1. 环境与入口

- 前端入口：`http://127.0.0.1:5173/login`
- 后端文档：`http://127.0.0.1:8000/docs`
- 健康检查：`http://127.0.0.1:8000/health`
- OpenAPI：`http://127.0.0.1:8000/openapi.json`

### 执行前检查

- 前后端服务均已启动
- MySQL 已连接到当前运行环境
- 浏览器 DevTools 可用，可检查 `Session Storage`、`Local Storage`、`Network`
- 下载目录可写
- 已准备测试文件：`VALID_PDF_FILE`、`VALID_DOCX_FILE`、`VALID_PPTX_FILE`、`VALID_TXT_FILE`、`VALID_MD_FILE`、`INVALID_FILE_TYPE`、`OVERSIZE_FILE`
- 如需执行全量重置，已准备强密码占位值：`BULK_RESET_DEFAULT_PASSWORD`

## 2. 账号与测试数据

### 2.1 账号占位符

| 类型 | 占位符 | 说明 |
| --- | --- | --- |
| 管理员 | `ADMIN_EMAIL / ADMIN_PASSWORD` | 真实角色必须为 `admin` |
| 普通用户 | `USER_EMAIL / USER_PASSWORD` | 用于普通用户主流程 |
| 被管理员代改的用户 | `RESET_TARGET_EMAIL / RESET_TARGET_PASSWORD` | 允许重复登录验证旧 token 失效 |

### 2.2 常用测试数据

| 名称 | 说明 |
| --- | --- |
| `NEW_USER_EMAIL` | 未注册邮箱 |
| `DUPLICATE_USER_EMAIL` | 已注册邮箱 |
| `INVALID_EMAIL` | 非法邮箱格式 |
| `VALID_NICKNAME` | 2-20 位合法昵称 |
| `SHORT_NICKNAME` | 少于 2 位昵称 |
| `LONG_NICKNAME` | 超过 20 位昵称 |
| `WEAK_PASSWORD` | 合法但弱，例如 6 位纯数字或单一类型字符 |
| `MEDIUM_PASSWORD` | `8+` 且至少两类字符 |
| `STRONG_PASSWORD` | `8+` 且包含大写、小写、数字、特殊字符 |
| `PASSWORD_WITH_SPACE` | 包含空格 |
| `BULK_RESET_DEFAULT_PASSWORD` | 全量重置统一密码，必须为强密码 |

### 2.3 页面基线

- 访客与认证：`/login`、`/register`
- 普通用户：`/dashboard`、`/agent`、`/study-plan`、`/upload-file`、`/quiz`、`/quiz-result`、`/learning-map`、`/change-password`
- 管理后台：`/admin/dashboard`、`/admin/models`、`/admin/prompts`、`/admin/config`、`/admin/users`、`/admin/api-logs`、`/admin/knowledge`

### 2.4 关键接口基线

- 认证：`POST /api/v1/auth/login-json`、`POST /api/v1/auth/register`、`POST /api/v1/auth/change-password`
- 普通用户：plan、files、quiz、analytics、learning-map、agent 相关接口
- 管理后台：`/api/v1/admin/*`
- 权限与运维：`PUT /api/v1/admin/users/{user_id}/password`、`backend/scripts/reset_all_user_passwords.py`

1. `SMOKE` 环境冒烟
2. `AUTH` 访客、注册、登录、自助改密
3. `DASH / AGENT / PLAN / UPLOAD / QUIZ / MAP`
4. `ADMIN` 管理后台
5. `API` 关键接口抽检
6. `COMPAT` 密码治理、安全、Git hook 专项
7. 结果汇总与风险登记
