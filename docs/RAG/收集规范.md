# 智学伴知识库 · 内容收集规范

> 本文档供小组成员收集整理知识内容时参考，请严格按照格式要求编写，以确保导入系统后能被正确检索。

---

## 一、文件格式要求

- 格式：**Markdown（`.md`）**
- 编码：**UTF-8**（用 VS Code / Typora 编写时默认即 UTF-8）
- 文件名：使用中文或拼音，**不含空格**，例如 `欧姆定律.md`、`pythagorean_theorem.md`

---

## 二、文件头（必须填写）

每个文件顶部必须包含以下 YAML 元数据块，用 `---` 包裹：

```
---
title: "知识点完整名称"
grade_level: "年级"
subject: "学科"
topic: "所属章节或单元"
difficulty: "难度"
source: "教材版本（可留空）"
tags: ["关键词1", "关键词2", "关键词3"]
---
```

### 字段填写规则

| 字段 | 是否必填 | 可填内容 |
|------|----------|----------|
| `title` | 必填 | 知识点完整名称，如"二次函数的图像与性质" |
| `grade_level` | 必填 | 只能填：`小学` / `初中` / `高中` / `大学` / `通用` |
| `subject` | 必填 | `数学` `语文` `英语` `物理` `化学` `生物` `历史` `地理` `政治` `信息技术` 等 |
| `topic` | 必填 | 所属章节/单元，如"函数""力学""有机化学""文言文" |
| `difficulty` | 必填 | 只能填：`easy`（基础）/ `medium`（中等）/ `hard`（难） |
| `source` | 可留空 | 教材版本，如"人教A版必修1""北师大版七年级下" |
| `tags` | 建议填 | 3~6 个关键词，用英文方括号和引号，如 `["定理", "直角三角形"]` |

---

## 三、正文结构（直接影响检索质量）

系统按 `##` 标题将文章切分为独立的知识块分别检索，因此：

- **用 `##` 划分小节**，每节控制在 300 字以内
- 每节内容独立完整，不依赖其他节才能理解
- 避免超长大段落，宁可多分几节

### 推荐结构模板

```markdown
# 知识点名称

## 定义/概念

（核心定义，100字以内，简洁准确）

## 公式/定理

（公式单独一行，写清每个符号的含义和单位）

## 推导过程（可选）

（如有需要，步骤清晰）

## 典型例题

（题目 + 解题步骤 + 答案，一道例题一个小节）

## 易错点

（常见错误和注意事项）

## 记忆口诀（可选）

（朗朗上口的记忆方法）
```

## 五、完整示例

### 示例1：初中物理

```markdown
---
title: "欧姆定律"
grade_level: "初中"
subject: "物理"
topic: "电路"
difficulty: "easy"
source: "人教版九年级上册"
tags: ["欧姆定律", "电阻", "电流", "电压", "串并联"]
---

# 欧姆定律

## 定律内容

导体中的电流，跟导体两端的电压成正比，跟导体的电阻成反比。

公式：I = U / R

- I：电流（单位：安培 A）
- U：电压（单位：伏特 V）
- R：电阻（单位：欧姆 Ω）

## 变形公式

| 求什么 | 公式 |
|--------|------|
| 电流 I | I = U / R |
| 电压 U | U = I × R |
| 电阻 R | R = U / I |

## 典型例题

灯泡电阻为 10Ω，两端电压为 220V，求通过灯泡的电流。

解：由欧姆定律 I = U/R = 220/10 = 22A

答：通过灯泡的电流为 22A。

## 易错点

1. 欧姆定律只适用于纯电阻电路，不能直接用于含电动机的电路
2. 公式中的 U、I、R 必须对应同一段导体，不能混用不同段的数据
```

### 示例2：高中数学

```markdown
---
title: "等差数列的通项公式与前n项和"
grade_level: "高中"
subject: "数学"
topic: "数列"
difficulty: "medium"
source: "人教A版必修5"
tags: ["等差数列", "通项公式", "前n项和", "公差"]
---

# 等差数列

## 定义

如果一个数列从第二项起，每一项与它的前一项的差都等于同一个常数，这个数列叫做等差数列。这个常数叫做公差，通常用 d 表示。

## 通项公式

an = a1 + (n-1)d

- a1：首项
- d：公差
- n：项数

## 前n项和公式

Sn = n×a1 + n(n-1)d/2

或等价形式：Sn = n(a1 + an)/2

## 典型例题

已知等差数列首项 a1 = 2，公差 d = 3，求第10项和前10项和。

解：
- a10 = 2 + (10-1)×3 = 2 + 27 = 29
- S10 = 10×(2+29)/2 = 10×31/2 = 155

## 易错点

1. 公差 d 可以为负数（递减数列）或 0（常数列）
2. 求 Sn 时注意两个公式的适用场合：已知 an 用第二个，只知 a1 和 d 用第一个
```

## 七、注意事项

1. **每个文件只写一个知识点**，不要把整章内容塞进一个文件
2. **不要复制粘贴大段连续文字**，系统按标题切片，无标题的长文效果很差
3. **数学公式直接用文字写**，如 `a² + b² = c²`，不需要 LaTeX
4. **引用图片时**，在文件同目录下建 `{文件名}_images/` 文件夹，图片放入后用 `![图片描述](./xxx_images/图片名.png)` 引用
5. **来源字段如实填写**，方便后续查验和版权标注
