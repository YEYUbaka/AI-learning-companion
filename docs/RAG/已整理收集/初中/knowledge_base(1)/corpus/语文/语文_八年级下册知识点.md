# 八年级下册语文完整版核心考点
## 一、古诗文必背默写
《桃花源记》《小石潭记》《核舟记》《北冥有鱼》《虽有嘉肴》全篇及名句默写；课外古诗词全覆盖，重点攻克通假字、生僻易错字。

## 二、文言文重难点
山水哲理类文言文为主；熟练掌握虚词：其/以/之/而；精通词类活用、古今异义、倒装句、省略句特殊句式翻译。

## 三、议论文阅读（本册核心难点）
1. 三要素：论点、论据、论证
2. 论据分类：事实论据、道理论据
3. 论证:举例论证、道 理论证、对比论证、比喻论证
4. 结构：引论—本论—结论

## 四、名著导读
《傅雷家书》《钢铁是怎样炼成的》：人物形象、主旨思想、经典情节常考填空简答。

## 1五、写作专项
材料作文、话题作文为主；观点明确，条理清晰；学会议论抒情结合，升华立意。

## 六、全书易错汇总
文言特殊句式翻译易丢分；议论文论点容易找不准；名著知识点记忆混淆；默写错别字高频失分。
