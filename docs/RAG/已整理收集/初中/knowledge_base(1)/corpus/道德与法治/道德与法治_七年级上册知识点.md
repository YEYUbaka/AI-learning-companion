# 七年级上册道德与法治核心考点
## 一、成长的节拍
中学时代是人生发展的新阶段，见证着从少年到青年的生命进阶。
学习不仅是知识的获取，也是能力的培养、品格的塑造，学习伴随终身。
正确认识自己，接纳、欣赏自己，通过自我评价和他人评价完善自我。
## 二、友谊的天空
友谊是一种亲密的关系，平等双向、相互尊重、互相关怀。
建立友谊需要开放自己、持续行动；呵护友谊需要用心关怀、尊重差异、正确处理冲突。
友谊有原则，不能不加分辨地为朋友做任何事，学会拒绝不良诱惑。
## 三、师生交往
教师是人类文明的传播者，承担教书育人的使命，尊重老师是基本道德规范。
正确对待老师的表扬与批评，主动与老师沟通，建立和谐的师生关系。
## 四、亲情之爱
家是身心的寄居之所，是心灵的港湾，孝亲敬长是中华民族的传统美德，也是法定义务。
体味亲情，学会与父母沟通，化解亲子冲突，理解父母的爱、回报父母。
## 五、生命的思考
生命是独特的、不可逆的、短暂的，要敬畏生命、珍视生命。
守护生命既要爱护身体，也要养护精神；增强生命韧性，学会发掘生命的力量，实现生命的价值。
