# 八年级上册道德与法治核心考点
## 一、社会生活讲道德
尊重他人是文明交往的前提，要做到尊重他人的人格、权利，学会换位思考。
文明有礼是一个人立身处世的前提，关乎国家形象，要做到语言文明、举止端庄。
诚信是中华民族的传统美德，是个人安身立命之本、企业无形资产、社会发展之基，要做到诚实守信。
## 二、遵守社会规则
社会规则划定自由的边界，保障人们的自由，要自觉遵守社会规则，学会自律和他律。
遵守社会公德、职业道德、家庭美德，维护社会秩序，做到文明有礼、遵纪守法。
违法行为分为民事违法行为、行政违法行为、刑事违法行为，要认清违法行为的危害，承担相应的法律责任。
## 三、勇担社会责任
责任是一个人分内应该做的事，来源于社会关系中的相互承诺，要对自己、他人、社会负责。
承担责任会有回报也会有代价，要主动承担责任，不言代价与回报，做负责任的人。
关爱他人是一种美德，要心怀善意、尽己所能、讲究策略，传递温暖。
服务社会体现人生价值，要积极参与公益活动，提升自身能力，奉献社会。
## 四、维护国家利益
国家利益是人民利益的集中体现，国家利益至上，要树立国家利益意识，坚决维护国家利益。
坚持国家利益与个人利益相结合，当二者发生矛盾时，自觉服从国家利益。
维护国家主权、安全、荣誉和利益，是每个公民的法定义务，要增强国家安全意识，履行维护国家安全的责任。
