# 九年级上册英语核心考点
## 一、宾语从句
三要素：引导词、语序、时态
语序统一用陈述语序；主句现在从句任意时态，主句过去从句统一过去相关时态。

## 二、情态动词表推测
must 肯定推测；might/may/could 可能；can't 不可能
注意：mustn't不表推测，只表禁止。

## 三、被动语态
结构：be + 过去分词
时态变化只改be动词；常考一般现在、一般过去被动。
不及物动词无被动；固定短语不能丢介词。

## 四、定语从句基础
先行词+关系代词who/that/which
基础用法：人用who/that，物用which/that。

## 五、重点短语与写作
交际建议、文化习俗话题作文；高级连接词提升书面表达。

## 易错提醒
宾语从句疑问语序不改；被动语态漏be动词；推测情态动词混用；定语从句关系词选错。
