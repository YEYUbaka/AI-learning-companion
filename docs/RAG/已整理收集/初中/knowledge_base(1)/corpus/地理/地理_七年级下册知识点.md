# 七年级下册地理核心考点
## 一、亚洲
面积最大、跨纬度最广；地势中部高四周低，河流呈放射状分布；季风气候显著，气候复杂多样。
## 二、东南亚
地处十字路口咽喉；热带季风与热带雨林气候；盛产水稻与热带经济作物；马六甲海峡交通要道。
## 2. 中东
三洲五海之地；全球石油核心产区；气候干旱水资源匮乏；宗教复杂冲突多发。
## 四、欧洲西部
温带海洋性气候广布；全年温和湿润，畜牧业发达；发达国家集中，旅游资源丰富。
## 五、撒哈拉以南非洲
高原大陆、热带大陆；经济单一ation落后；人口增长过快,人地矛盾加剧。
## 六、美洲与大洋洲
北美经济发达；南美亚马孙雨林广布；澳大利亚独占大陆，特有生物多。
