# 九年级上册历史核心考点
## 一、古代亚非欧文明
古埃及金字塔、象形文字；古巴比伦《汉谟拉比法典》；古印度种姓制度与佛教。古希腊雅典民主政治；罗马帝国兴衰；中世纪西欧封建制度、教会神权统治。
## 二、步入近代
文艺复兴：人文主义思想解放；新航路开辟，世界开始连为整体；早期殖民掠夺积累资本。
## 三、欧美资产阶级革命
英国资产阶级革命，确立君主立宪制；美国独立战争，颁布《独立宣言》；法国大革命传播自由平等，摧毁封建制度。
## 四、工业革命与马克思主义
第一次工业革命蒸汽机普及，人类进入蒸汽时代；马克思主义诞生，无产阶级斗争有科学理论指导。
## 五、资本主义制度扩展
俄国1861农奴制改革、日本明治维新，走上资本主义道路；美国南北战争维护统一，废除黑人奴隶制。
## 六、第二次工业革命
电力与内燃机应用，进入电气时代；科技推动生产力飞跃，垄断资本主义形成。
