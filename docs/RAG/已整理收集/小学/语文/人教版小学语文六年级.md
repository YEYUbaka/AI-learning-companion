## 综合知识
1. 小学全部汉字、词语、成语系统掌握
2. 修辞手法综合运用
3. 句式变换熟练掌握

## 阅读考点
1. 概括主要内容、中心思想
2. 理解句子含义与作用
3. 分析人物形象、写作特点
4. 散文、记叙文、说明文、简单文言文阅读

## 习作能力
1. 500字左右考场作文
2. 审题、立意、选材、结构完整
3. 语言生动，有细节描写
4. 会写记叙文、说明文、应用文、想象作文

## 小升初必备
1. 必背古诗75首
2. 文言文短篇：《伯牙鼓琴》《书戴嵩画牛》等
3. 名言警句、俗语谚语
4. 文学常识：作者、朝代、课文出处
