# 上下文记忆问题排查指南

## 问题现象

AI对话没有上下文记忆，无法记住之前的对话内容。

## 已实施的修复

### 1. 前端修改 ✅
- 在发送请求前构建对话历史
- 过滤空消息
- 转换role格式（ai → assistant）
- 添加调试日志

### 2. 后端修改 ✅
- 接收history参数
- 处理Pydantic模型和字典两种格式
- 构建完整消息列表
- 添加详细调试日志

## 排查步骤

### 步骤1：检查前端控制台

打开浏览器开发者工具（F12），查看Console标签：

1. 发送消息时，应该看到：
   ```
   📝 构建的对话历史: {原始消息数: X, 过滤后消息数: Y, ...}
   📤 发送请求: {模型: ..., 历史消息数: ...}
   ```

2. 如果历史消息数为0，说明前端没有正确构建历史

### 步骤2：检查后端日志

查看后端控制台输出：

1. 应该看到：
   ```
   [DEBUG] 路由层 - 收到对话历史: X条消息
   [DEBUG] 路由层 - 历史消息示例（前3条）: ...
   [DEBUG] 消息列表长度: X (包含Y条历史消息)
   ```

2. 如果历史消息数为0，说明后端没有收到历史

### 步骤3：验证消息格式

检查后端日志中的"完整消息列表"，应该包含：
- [1] system: ...（系统提示）
- [2] user: ...（历史用户消息）
- [3] assistant: ...（历史AI回复）
- [4] user: ...（当前问题）

## 可能的问题

### 问题1：前端历史为空

**原因**：messages数组为空或只包含当前消息

**解决**：确保在添加新消息之前构建历史

### 问题2：后端没有收到历史

**原因**：Pydantic验证失败或格式不匹配

**解决**：检查后端日志，确认history字段是否正确解析

### 问题3：消息格式错误

**原因**：role格式不匹配（ai vs assistant）

**解决**：确保前端发送assistant，后端正确转换

## 测试方法

1. 清空聊天记录
2. 发送第一条消息："出几个王者荣耀题目"
3. 等待AI回复
4. 发送第二条消息："我的答案是1A 2B 3C"
5. 检查AI是否理解这是对题目的回答

## 调试命令

在后端控制台查看详细日志：
- 历史消息数量
- 历史消息内容（前几条）
- 完整消息列表

如果问题仍然存在，请提供：
1. 前端控制台的完整日志
2. 后端控制台的完整日志
3. 网络请求的Payload（在Network标签中查看）
