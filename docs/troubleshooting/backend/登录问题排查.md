### 步骤3：测试登录

1. 打开前端页面：http://localhost:5173/login
2. 输入：
   - 邮箱：`test@example.com`

## 如果仍然失败

### 检查1：查看后端日志
查看后端控制台是否有错误信息

### 检查2：测试API
使用 curl 或 Postman 测试登录接口：

```bash
curl -X POST http://127.0.0.1:8000/api/v1/auth/login-json \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"123456"}'
```

### 检查3：重置密码（如果需要）
如果密码确实不对，可以重置：

```bash
cd backend
python 重置用户密码.py test@example.com 123456
```
