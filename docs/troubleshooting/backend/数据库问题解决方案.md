# 🗄️ 数据库连接问题 - 解决方案

## ✅ 好消息：服务已经在运行！

从你的启动日志可以看到：
```
INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
INFO:     Application startup complete.
```

**服务已经成功启动了！** 🎉

只是数据库连接失败，但这不影响 AI 问答功能的使用。

## 🔍 问题分析

错误信息：
```
❌ 数据库表创建失败: SQL Server 不存在或访问被拒绝
```

可能的原因：
1. SQL Server 未安装或未启动
2. SQL Server 配置不正确
3. 数据库 `ZhixueBan` 不存在
4. 连接字符串配置有误

## 💡 解决方案

### 方案一：修复数据库连接（完整功能）

#### 1. 检查 SQL Server 是否运行

打开"服务"管理器（services.msc），查找：
- SQL Server (MSSQLSERVER)
- SQL Server Browser

确保这两个服务都已启动。

#### 2. 创建数据库

打开 SQL Server Management Studio (SSMS)，执行：
```sql
CREATE DATABASE ZhixueBan;
```

#### 3. 检查连接信息

确认 `backend/database.py` 中的连接字符串：
```python
SQLALCHEMY_DATABASE_URL = (
    "mssql+pyodbc://sa:123456@localhost/ZhixueBan"
    "?driver=SQL+Server"
    "&Trusted_Connection=no"
    "&charset=utf-8"
)
```

#### 4. 测试 ODBC 驱动

在命令提示符运行：
```bash
odbcinst -q -d
```
确认能看到 "SQL Server" 驱动。

### 方案二：先测试 AI 功能（无需数据库）

即使数据库连接失败，**AI 问答功能仍可正常使用**！

#### 测试步骤：

1. **确保服务在运行**
   - 已经看到 "Application startup complete"
   
2. **访问 API 文档**
   ```
   http://127.0.0.1:8000/docs
   ```

3. **测试 AI 问答接口**
   - 点击 `POST /api/v1/ai/ask`
   - 点击 "Try it out"
   - 输入测试数据：
     ```json
     {
       "prompt": "帮我写一份三天的Python学习计划"
     }
     ```
   - 点击 "Execute"

4. **查看结果**
   - 应该能看到 AI 的回答

### 方案三：使用 SQLite（更简单）

如果暂时不需要 SQL Server，可以快速切换到 SQLite：

#### 1. 修改 `database.py`

将：
```python
SQLALCHEMY_DATABASE_URL = (
    "mssql+pyodbc://sa:123456@localhost/ZhixueBan"
    "?driver=SQL+Server"
    "&Trusted_Connection=no"
    "&charset=utf-8"
)
```

改为：
```python
SQLALCHEMY_DATABASE_URL = "sqlite:///./zhixueban.db"
```

#### 2. 安装 SQLite 支持
```bash
pip install pysqlite3
```

#### 3. 重启服务
