## 🚀 方法二：使用 FTP 工具（如 FileZilla）

### 步骤：

1. **打开 FileZilla 或 WinSCP**

2. **连接到服务器**
   - 主机：`47.114.103.200`（你的服务器IP）
   - 用户名：`Administrator`（或你的用户名）
   - 密码：你的服务器密码
   - 端口：`22`（SSH）或 `21`（FTP）

3. **上传文件**
   - 左侧：本地文件（`F:\Cursor projects\Web\frontend\`）
   - 右侧：服务器文件（`C:\Web\Zhixueban\frontend\`）

## ✅ 更新后验证

1. **刷新浏览器**
   - 清除缓存：`Ctrl + F5` 或 `Ctrl + Shift + R`
   - 或在手机浏览器中刷新

2. **检查功能**
   - 导航栏在移动端是否显示正常
   - 菜单按钮是否可用
   - 文字是否完整显示
   - 按钮是否易于点击

---

## 📝 注意事项

1. **备份原文件**（可选）
   - 复制前可以先备份服务器上的原文件
   - 如果出问题可以快速恢复

2. **开发模式 vs 生产模式**
   - 如果使用 `npm run dev`（开发模式），修改后会自动热更新
   - 如果使用 `npm run build`（生产模式），需要重新构建

3. **浏览器缓存**
   - 更新后记得清除浏览器缓存
   - 移动端可能需要强制刷新

---

## 🔧 如果更新后没有效果

1. **检查文件是否正确复制**
   - 确认文件路径正确
   - 确认文件内容已更新

2. **重启前端服务**
   ```powershell
   # 停止当前服务（关闭窗口）
   # 重新启动
   cd C:\Web\Zhixueban\部署脚本
   .\启动前端服务.bat
   ```

3. **清除浏览器缓存**
   - 桌面浏览器：`Ctrl + Shift + Delete`
   - 手机浏览器：清除缓存或使用无痕模式

4. **检查控制台错误**
   - 按 `F12` 打开开发者工具
   - 查看 Console 是否有错误
