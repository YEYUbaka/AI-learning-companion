# 🚀 Windows 服务器详细部署步骤

## 📦 第一步：准备上传文件

### 1.1 清理项目（在本地执行）

运行清理脚本：
```powershell
.\部署脚本\清理项目.bat
```

或手动删除：
- `backend/__pycache__/` 目录
- `backend/venv/` 目录（虚拟环境）
- `backend/logs/` 目录
- `backend/*.db` 文件
- `frontend/node_modules/` 目录
- `frontend/dist/` 目录
- 所有测试文件和临时文档

### 1.2 需要上传的文件

**必须上传**：
```
✅ backend/              # 整个目录（排除 venv、__pycache__、logs）
✅ frontend/             # 整个目录（排除 node_modules、dist）
✅ 部署脚本/             # 部署脚本目录
✅ Windows服务器部署指南.md
```

**不需要上传**：
```
❌ backend/venv/         # 虚拟环境（在服务器上重新创建）
❌ backend/__pycache__/   # Python 缓存
❌ backend/logs/         # 日志文件
❌ backend/*.db          # 数据库文件
❌ frontend/node_modules/ # Node 依赖（在服务器上重新安装）
❌ frontend/dist/        # 构建产物（在服务器上重新构建）
```

## ⚙️ 第三步：配置环境

### 3.1 配置后端环境变量

1. **进入后端目录**：
   ```powershell
   cd C:\zhixueban\backend
   ```

2. **创建 `.env` 文件**：
   ```powershell
   # 如果不存在，创建新文件
   notepad .env
   ```

3. **填入以下内容**（根据实际情况修改）：
   ```env
   # ============================================
   # 数据库配置
   # ============================================
   DATABASE_URL=sqlite:///./zhixueban.db
   
   # ============================================
   # JWT 密钥（重要！必须修改为随机字符串）
   # ============================================
   # 生成方法：python -c "import secrets; print(secrets.token_urlsafe(32))"
   SECRET_KEY=请替换为至少32个字符的随机字符串
   ALGORITHM=HS256
   ACCESS_TOKEN_EXPIRE_MINUTES=43200
   
   # ============================================
   # 加密密钥（用于加密存储的API密钥）
   # ============================================
   # 生成方法：python -c "import secrets; print(secrets.token_urlsafe(32))"
   ENCRYPTION_KEY=请替换为至少32个字符的随机字符串
   
   # ============================================
   # AI 模型 API 密钥（根据实际情况填写）
   # ============================================
   # DeepSeek（必须，主要使用的模型）
   DEEPSEEK_API_KEY=sk-你的DeepSeek密钥
   
   # OpenAI（可选）
   OPENAI_API_KEY=sk-你的OpenAI密钥
   
   # 星火大模型（可选）
   SPARK_API_KEY=你的星火API密钥
   SPARK_API_SECRET=你的星火API密钥
   SPARK_APP_ID=你的星火AppID
   
   # ============================================
   # 服务器配置
   # ============================================
   BACKEND_HOST=0.0.0.0
   BACKEND_PORT=8000
   ```

4. **生成密钥**（如果不知道如何生成）：
   ```powershell
   python -c "import secrets; print('SECRET_KEY=' + secrets.token_urlsafe(32))"
   python -c "import secrets; print('ENCRYPTION_KEY=' + secrets.token_urlsafe(32))"
   ```
   
   将输出的密钥复制到 `.env` 文件中。

### 3.2 配置前端 API 地址

1. **编辑前端 API 配置文件**：
   ```powershell
   notepad C:\zhixueban\frontend\src\api\apiClient.js
   ```

2. **找到这一行**（大约第 10 行）：
   ```javascript
   const API_BASE_URL = 'http://localhost:8000/api/v1';
   ```

3. **修改为服务器地址**：
   ```javascript
   // 方式一：使用 IP 地址（开发环境）
   const API_BASE_URL = 'http://你的服务器IP:8000/api/v1';
   
   // 方式二：使用域名（生产环境，推荐）
   // const API_BASE_URL = 'https://your-domain.com/api/v1';
   ```

   **示例**：
   ```javascript
   // 如果服务器 IP 是 123.456.789.0
   const API_BASE_URL = 'http://123.456.789.0:8000/api/v1';
   ```

4. **保存文件**

## 🔧 常见问题解决

### 问题 1：端口被占用

**错误信息**：`Address already in use`

**解决方法**：
```powershell
# 查看端口占用
netstat -ano | findstr :8000

# 结束进程（替换 <PID> 为实际进程ID）
taskkill /PID <PID> /F
```

### 问题 2：虚拟环境激活失败

**错误信息**：`无法加载文件，因为在此系统上禁止运行脚本`

**解决方法**：
```powershell
# 以管理员身份运行 PowerShell，执行：
Set-ExecutionPolicy RemoteSigned
```

### 问题 3：npm install 失败

**解决方法**：
```powershell
# 清除缓存
npm cache clean --force

# 删除 node_modules 重新安装
cd C:\zhixueban\frontend
rmdir /s /q node_modules
npm install
```

### 问题 4：数据库连接失败

**解决方法**：
1. 检查 `backend/.env` 中的 `DATABASE_URL`
2. 确保数据库文件有写入权限
3. 检查磁盘空间是否充足

### 问题 5：无法外网访问

**解决方法**：
1. 检查防火墙是否开放端口
2. 检查服务器安全组规则（云服务器）
3. 确认服务绑定到 `0.0.0.0` 而不是 `127.0.0.1`
