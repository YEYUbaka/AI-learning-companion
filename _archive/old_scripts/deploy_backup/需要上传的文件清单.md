## 📋 上传前准备清单

### 1. 清理项目（在本地执行）

创建 `清理项目.bat` 脚本：

```batch
@echo off
echo 清理不需要的文件...

:: 删除 Python 缓存
for /d /r backend %%d in (__pycache__) do @if exist "%%d" rd /s /q "%%d"
del /s /q backend\*.pyc 2>nul

:: 删除日志文件
del /s /q backend\logs\*.log 2>nul
del /s /q logs\*.log 2>nul

:: 删除测试文件
del /s /q backend\test_*.py 2>nul
del /s /q backend\快速*.py 2>nul
del /s /q backend\测试*.py 2>nul

:: 删除临时文档
del /q backend\修复*.md 2>nul
del /q backend\问题*.md 2>nul
del /q backend\*.bat 2>nul

echo 清理完成！
pause
```

## ⚙️ 配置修改步骤

### 第一步：配置后端环境变量

1. **进入后端目录**：
   ```powershell
   cd C:\zhixueban\backend
   ```

2. **创建 `.env` 文件**（如果不存在）：
   ```powershell
   copy .env.example .env
   # 或者手动创建
   ```

3. **编辑 `.env` 文件**，填入以下配置：
   ```env
   # 数据库配置（SQLite，默认即可）
   DATABASE_URL=sqlite:///./zhixueban.db
   
   # JWT 密钥（重要！必须修改）
   # 运行 python generate_keys.py 生成，或使用以下命令：
   # python -c "import secrets; print(secrets.token_urlsafe(32))"
   SECRET_KEY=你的密钥（至少32个字符）
   ALGORITHM=HS256
   
   # 加密密钥（用于加密存储的API密钥）
   ENCRYPTION_KEY=你的加密密钥（至少32个字符）
   
   # AI 模型 API 密钥（根据实际情况填写）
   DEEPSEEK_API_KEY=sk-你的DeepSeek密钥
   OPENAI_API_KEY=sk-你的OpenAI密钥（可选）
   SPARK_API_KEY=你的星火密钥（可选）
   SPARK_API_SECRET=你的星火密钥（可选）
   SPARK_APP_ID=你的星火AppID（可选）
   
   # 服务器配置
   BACKEND_HOST=0.0.0.0        # 0.0.0.0 允许外网访问
   BACKEND_PORT=8000            # 后端端口
   ```

### 第二步：配置前端 API 地址

1. **编辑 `frontend/src/api/apiClient.js`**：

   找到这一行（大约第 10 行）：
   ```javascript
   const API_BASE_URL = 'http://localhost:8000/api/v1';
   ```

   修改为你的服务器地址：
   ```javascript
   // 方式一：使用 IP 地址
   const API_BASE_URL = 'http://你的服务器IP:8000/api/v1';
   
   // 方式二：使用域名（推荐生产环境）
   const API_BASE_URL = 'https://your-domain.com/api/v1';
   ```

   **示例**：
   ```javascript
   // 如果服务器 IP 是 123.456.789.0
   const API_BASE_URL = 'http://123.456.789.0:8000/api/v1';
   ```

### 第三步：生成 JWT 密钥（如果还没有）

```powershell
cd C:\zhixueban\backend
python -c "import secrets; print('SECRET_KEY=' + secrets.token_urlsafe(32))"
python -c "import secrets; print('ENCRYPTION_KEY=' + secrets.token_urlsafe(32))"
```

将输出的密钥复制到 `.env` 文件中。

## 🚀 运行步骤

### 方法一：使用一键部署脚本（推荐首次部署）

1. **运行一键部署**：
   ```powershell
   cd C:\zhixueban\部署脚本
   .\一键部署.bat
   ```
   
   这个脚本会：
   - 检查 Python 和 Node.js 环境
   - 创建后端虚拟环境
   - 安装所有依赖
   - 初始化数据库
   - 构建前端
   - 创建启动脚本

2. **配置环境变量**（如果还没配置）：
   - 编辑 `backend\.env`
   - 编辑 `frontend\src\api\apiClient.js`

3. **配置防火墙**（需要管理员权限）：
   ```powershell
   .\配置防火墙.bat
   ```

4. **启动服务**：
   ```powershell
   .\一键启动前后端.bat
   ```

### 方法二：手动部署（适合熟悉流程的用户）

#### 1. 配置后端

```powershell
# 进入后端目录
cd C:\zhixueban\backend

# 创建虚拟环境
python -m venv venv

# 激活虚拟环境
.\venv\Scripts\activate

# 升级 pip
python -m pip install --upgrade pip

# 安装依赖
pip install -r requirements.txt

# 创建 .env 文件并配置（见上面的配置步骤）

# 初始化数据库
python -c "from database import engine, Base; Base.metadata.create_all(bind=engine)"
```

#### 2. 配置前端

```powershell
# 进入前端目录
cd C:\zhixueban\frontend

# 安装依赖
npm install

# 编辑 src/api/apiClient.js，修改 API 地址

# 构建前端（生产模式）
npm run build
```

#### 3. 启动服务

**启动后端**：
```powershell
cd C:\zhixueban\backend
.\venv\Scripts\activate
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

**启动前端（开发模式）**：
```powershell
cd C:\zhixueban\frontend
npm run dev -- --host 0.0.0.0
```

**或使用生产模式（需要 Nginx）**：
- 前端已构建在 `frontend/dist` 目录
- 配置 Nginx 指向该目录

## 🔧 常见问题

### Q: 端口被占用怎么办？

```powershell
# 查看端口占用
netstat -ano | findstr :8000

# 结束进程（替换 <PID> 为实际进程ID）
taskkill /PID <PID> /F
```

### Q: 虚拟环境激活失败？

```powershell
# 以管理员身份运行 PowerShell，执行：
Set-ExecutionPolicy RemoteSigned
```

### Q: npm install 失败？

```powershell
# 清除缓存
npm cache clean --force

# 删除 node_modules 重新安装
rmdir /s /q node_modules
npm install
```

### Q: 如何让服务开机自启？

使用 NSSM 将服务注册为 Windows 服务（详见部署指南）。
