# 🔧 服务管理说明

## 📋 问题说明

### 问题 1：服务停止
- **现象**：过了一晚上后，登录网页显示"无法连接到服务器"
- **原因**：后端服务可能因为以下原因停止：
  - 服务器重启
  - 进程崩溃
  - 网络错误
  - 资源不足

### 问题 2：恶意扫描
- **现象**：日志中出现大量访问 `.env`、`.git/config` 等敏感文件的请求
- **原因**：这是常见的自动化安全扫描，试图获取敏感信息
- **解决**：已添加安全中间件，自动阻止这些请求

---

## 🛠️ 解决方案

### 1. 添加安全防护

已创建 `backend/core/security_middleware.py`，自动阻止访问：
- `.env` 文件
- `.git/` 目录
- 其他敏感文件和目录

**效果**：
- 恶意请求返回 404（不暴露敏感信息）
- 记录安全警告日志
- 不影响正常请求

### 2. 服务管理脚本

已创建以下脚本：

#### ✅ `检查服务状态.bat`
- 检查后端和前端服务是否运行
- 显示进程 ID
- 快速诊断问题

#### ✅ `自动启动服务.bat`
- 自动启动后端和前端服务
- 在新窗口中运行
- 适合手动启动

#### ✅ `重启服务.bat`
- 先停止现有服务
- 再启动新服务
- 适合服务异常时使用

## 📊 监控服务

### 方法一：使用检查脚本

定期运行：
```powershell
.\部署脚本\检查服务状态.bat
```

### 方法二：使用 PowerShell 监控

创建 `监控服务.ps1`：
```powershell
while ($true) {
    $backend = netstat -ano | Select-String ":8000" | Select-String "LISTENING"
    $frontend = netstat -ano | Select-String ":5173" | Select-String "LISTENING"
    
    if (-not $backend) {
        Write-Host "[$(Get-Date)] Backend service is down!" -ForegroundColor Red
        # 可以添加自动重启逻辑
    }
    
    if (-not $frontend) {
        Write-Host "[$(Get-Date)] Frontend service is down!" -ForegroundColor Red
    }
    
    Start-Sleep -Seconds 60
}
```

## 🐛 常见问题

### Q1: 服务启动后立即停止

**可能原因**：
- 端口被占用
- 依赖未安装
- 配置文件错误

**解决方法**：
1. 检查端口占用：`netstat -ano | findstr ":8000"`
2. 重新安装依赖：`.\部署脚本\安装依赖.bat`
3. 检查 `.env` 文件配置

### Q2: 服务运行一段时间后停止

**可能原因**：
- 内存不足
- 异常崩溃
- 网络问题

**解决方法**：
1. 查看错误日志：`backend/logs/error.log`
2. 增加系统资源
3. 设置自动重启（任务计划程序）

### Q3: 无法访问服务

**可能原因**：
- 防火墙阻止
- 服务未启动
- 端口配置错误

**解决方法**：
1. 检查服务状态：`.\部署脚本\检查服务状态.bat`
2. 检查防火墙：`.\部署脚本\配置防火墙.bat`
3. 检查端口配置
