# 🚀 快速启动指南（演示用）

## 📍 项目位置
`C:\Web\Zhixueban`

---

## ⚡ 最快启动方式（3步）

### 第一步：检查配置

1. **检查后端 `.env` 文件**：
   ```
   C:\Web\Zhixueban\backend\.env
   ```
   
   如果不存在，创建它并填入：
   ```env
   DATABASE_URL=sqlite:///./zhixueban.db
   SECRET_KEY=临时演示密钥123456789012345678901234567890
   ENCRYPTION_KEY=临时演示密钥123456789012345678901234567890
   DEEPSEEK_API_KEY=sk-你的密钥（如果没有可以暂时不填，部分功能可能不可用）
   BACKEND_HOST=0.0.0.0
   BACKEND_PORT=8000
   ```

2. **检查前端 API 地址**（可选，已自动检测）：
   ```
   C:\Web\Zhixueban\frontend\src\api\apiClient.js
   ```
   通常不需要修改，会自动检测服务器 IP。

### 第二步：启动后端

**方法一：使用脚本（推荐）**
```powershell
cd C:\Web\Zhixueban\部署脚本
.\启动后端服务.bat
```

**方法二：手动启动**
```powershell
cd C:\Web\Zhixueban\backend

# 如果虚拟环境存在，激活它
.\venv\Scripts\activate

# 如果虚拟环境不存在，先创建
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt

# 启动服务
python -m uvicorn main:app --host 0.0.0.0 --port 8000
```

### 第三步：启动前端（新开一个窗口）

**方法一：使用脚本（推荐）**
```powershell
cd C:\Web\Zhixueban\部署脚本
.\启动前端服务.bat
```

**方法二：手动启动**
```powershell
cd C:\Web\Zhixueban\frontend

# 如果 node_modules 不存在，先安装
npm install

# 启动服务
npm run dev -- --host 0.0.0.0
```

## 🎯 一键启动（最简单）

直接运行：
```powershell
cd C:\Web\Zhixueban\部署脚本
.\一键启动前后端.bat
```

这会自动打开两个窗口，分别运行前端和后端。

## ✅ 验证启动成功

1. **后端**：访问 `http://你的服务器IP:8000/docs`
   - 应该看到 API 文档页面

2. **前端**：访问 `http://你的服务器IP:5173`
   - 应该看到登录页面

## 🔧 常见问题

### Q1: 虚拟环境不存在？
```powershell
cd C:\Web\Zhixueban\backend
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
```

### Q2: node_modules 不存在？
```powershell
cd C:\Web\Zhixueban\frontend
npm install
```

### Q3: 端口被占用？
```powershell
# 查看端口占用
netstat -ano | findstr :8000
netstat -ano | findstr :5173

# 结束进程（替换 <PID> 为实际进程ID）
taskkill /PID <PID> /F
```

### Q4: 无法外网访问？
1. 检查防火墙是否开放端口
2. 运行 `.\配置防火墙.bat`（需要管理员权限）
3. 如果是云服务器，检查安全组规则

## 📝 演示注意事项

1. **数据库**：使用 SQLite，首次启动会自动创建
2. **API 密钥**：如果没有配置 AI API 密钥，AI 相关功能可能不可用
3. **端口**：
   - 后端：8000
   - 前端：5173
4. **停止服务**：关闭对应的命令行窗口即可
