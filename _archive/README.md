# 归档目录说明

本目录用于存放不常用的文件和备份。

## 目录内容

### old_scripts/
- `bash_backup/`: 原 bash/ 文件夹的备份
- `deploy_backup/`: 原 部署脚本/ 文件夹的备份

这些脚本已经整合到 `scripts/` 目录中，此处保留作为备份。

### temp_files/
- `backend_test_files/`: 后端临时测试文件
  - 各种测试脚本（test_*.py）
  - 调试脚本（调试*.py）
  - 检查脚本（检查*.py）

这些文件为开发过程中的临时测试文件，已归档备份。

### 其他文件
- `AI-learning-companion-main.zip`: 项目压缩包备份

## 清理建议

如果确认不再需要这些文件，可以安全删除本目录以节省空间。

建议在删除前：
1. 确认新的脚本目录 `scripts/` 功能正常
2. 确认不需要这些测试文件
3. 做好项目的 Git 提交或其他备份
