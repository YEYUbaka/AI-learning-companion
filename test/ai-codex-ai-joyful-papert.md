# 智学伴 AI 个性化学习平台 - 商业级全量测试方案

## Context

用户需要一份覆盖整个项目的商业级测试方案，不仅仅测试 Agent 页面，而是对所有 17 个前端页面 + ~75 个后端 API + 系统集成的全面测试。要求确保功能完整无漏洞，达到商业级项目标准。

## 测试范围

- **前端页面**: 17 个（登录、注册、仪表盘、Agent 对话、学习计划、测验、测验结果、知识图谱、文件上传、知识文档、管理后台 7 个子页面）
- **后端 API**: ~75 个端点
- **安全测试**: 认证、授权、加密、XSS、SQL 注入、CSRF、文件上传安全
- **性能测试**: 页面加载、API 响应、SSE 稳定性、并发
- **已知缺陷回归**: 14 个已知问题

## 十二、已知缺陷回归清单

基于代码审查发现的14个BUG：

1. **BUG-001**: 多处使用native `alert()` 而非UI通知(Register/Config/PromptEditor)
2. **BUG-002**: Dashboard API错误静默处理(logger.error但无用户反馈)
3. **BUG-003**: QuizResult刷新数据丢失(依赖location.state)
4. **BUG-004**: UploadFile刷新文件状态丢失
5. **BUG-005**: QuestionBank无分页(hardcoded limit 50)
6. **BUG-006**: KnowledgeAdmin警告banner被永久隐藏
7. **BUG-007**: ChatSession/ChatMessage未在models/__init__.py注册
8. **BUG-008**: QuizPaper/PaperTemplate未在models/__init__.py注册
9. **BUG-009**: 无全局404页面
10. **BUG-010**: 无React Error Boundary
11. **BUG-011**: UploadFile仅用text_preview传给AI(可能截断)
12. **BUG-012**: 无速率限制(登录/注册/API调用)
13. **BUG-013**: CORS allow_origins=["*"]生产环境过于宽松
14. **BUG-014**: get_current_admin双逻辑(role检查+email检查+自升admin)
